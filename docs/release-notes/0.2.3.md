Passenger 0.2.3 colours every language but C# far faster, with nothing native left to carry for it, and fixes what 0.2.2 left. It is still free and open source under MIT, and everything it closed is in its [0.2.3 milestone](https://github.com/Zaneris/passenger/milestone/5).

## Faster

- **Colour for every language but C#** comes from Tint, Sébastien Ros's TextMate engine on his managed regular expressions, in place of TextMateSharp and its native Oniguruma: a full file of CSS colours about 13 times as fast and JavaScript 7 times, with a small fraction of the allocations, and no native library per system to carry or sign. Where colours differ, they now match VS Code's own tokenizer ([#572](https://github.com/Zaneris/passenger/pull/572)). Thanks to Sébastien Ros for the change.

## Fixed

- **The Problems window** no longer lists every problem again, and loses the row chosen, each time the open file's problems change while its Solution or Build tab is shown: a key that typed or mended an error rebuilt and sorted thousands of rows.
- **A key added to a `.resx`** whose last entry was an image or a file is written as a string, where it took that entry's type, so the IDE and the build ignored it.
- **Each kind of file gets what its kindred kinds get** ([#595](https://github.com/Zaneris/passenger/issues/595)): XAML Preview stays on or off from one window to the next, as Markdown's does; File Structure outlines JSON, YAML, CSS and TypeScript as the Structure window does; a .gitignore or .editorconfig comments a line with `#`, the .editorconfig coloured; a .slnf is coloured, folded and checked as the JSON it is; and the status bar names XAML and MSBuild files rather than XML.
- **The status bar's widgets act**: a click on the caret's place opens Go to Line, and one on the indent offers a tab or 2, 4 or 8 spaces for the file until Automatic gives it back its own.
- **Go to Related File** switches between a XAML or Razor file and its code-behind, both ways, and the active tab stays in sight however many tabs crowd the strip.
- **Every button names its keys** ([#592](https://github.com/Zaneris/passenger/issues/592)): the title bar's buttons give the keys of the keymap in force (Run (⌃F5)), and a tool window's Hide gives the keymap's own key rather than a fixed ⇧⎋.
- **An empty window says how to fill it**: the Run and Build windows before anything has run, and Find, Hierarchy, Bookmarks, Structure, Local History and the editor area with the keys of what fills them; an empty Hierarchy window no longer shows an empty bar.
- **An HTML page opens in your browser** from the Explorer's Open In, its editor's menu or Alt+F2 (Ctrl+Alt+F2 in Visual Studio's keymap off the Mac) ([#597](https://github.com/Zaneris/passenger/issues/597)).
- **A CSV, TSV or workbook table** has a right-click menu with Copy and Select All.
- **F4 or Jump to Source in a diff** opens the file at the line you're on.
