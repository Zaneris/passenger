Passenger 0.3.4 starts a solution's projects together, shows a setting as you change it, and sets usages in generated code apart from yours. It also fixes more than twenty things you could run into on 0.3.3: exception stops on .NET 11, attaching again to a program in a container, NuGet's Update All under central package management, and terminal tabs that could reach into each other. It is still free and open source under MIT, and everything it closed is in its [0.3.4 milestone](https://github.com/Zaneris/passenger/milestone/12).

## Highlights

- **Start several projects as one** ([#1451](https://github.com/Zaneris/passenger/issues/1451)): a solution's launch profiles, kept in the `.slnLaunch` file Visual Studio reads too, are run configurations. Run builds once and starts each project in its own launch profile, each in a Terminal tab; Debug debugs the projects you mark for it and runs the rest; Stop ends them all. Make and change the profiles in Edit Configurations, shared with your team or kept as your own (`.slnLaunch.user`); renaming or moving a project updates them.
- **See a setting before you apply it** ([#1452](https://github.com/Zaneris/passenger/issues/1452)): the theme, colour scheme, fonts, line spacing, ligatures, hints, soft wrap, and the terminal's font and cursor change in every window as you pick them, and go back if you close Settings without applying.
- **Find Usages sets generated code apart** ([#1460](https://github.com/Zaneris/passenger/issues/1460)): usages in source generators' output and designer files are grouped after the ones you wrote, with a filter to show either side, so a generator-heavy codebase no longer buries your own.
- **Delete several files at once** ([#1537](https://github.com/Zaneris/passenger/issues/1537)): choose several rows in the Explorer and Delete moves them all to the Trash after one question.
- **The Explorer keeps its view** ([#1478](https://github.com/Zaneris/passenger/issues/1478)): a folder opens again in the Files or Solution view you last used there.

## Fixed

- **Exception stops on .NET 11 show your code** ([#1503](https://github.com/Zaneris/passenger/issues/1503)): the stack and Variables showed the runtime's own exception handling where the frame that threw belonged. A step out of an async method from such an exception now stops where its caller catches it.
- **A step out of a static constructor stops** ([#1511](https://github.com/Zaneris/passenger/issues/1511)): with Just My Code off, it ran the program to its end.
- **Attach to a program in a container again after Stop** ([#1521](https://github.com/Zaneris/passenger/issues/1521)): stopping a container's main process left the debugger holding it, and every attach after that timed out. The program now runs on, and you can attach to it again.
- **Stops in a container open your files** ([#1523](https://github.com/Zaneris/passenger/issues/1523)): a program whose image was built from the open folder maps the image's source paths back to your files, so its frames open and show their lines.
- **Hovering while paused asks only about the code that stopped** ([#1522](https://github.com/Zaneris/passenger/issues/1522)): a name in another file no longer shows an evaluation error.
- **A conditional breakpoint in a parallel loop stops where it should** ([#1500](https://github.com/Zaneris/passenger/issues/1500)): a thread started while the condition was checked could run past the breakpoint and stop later, with no Variables to show.
- **Hot Reload's helper keeps out of an early stop** ([#1495](https://github.com/Zaneris/passenger/issues/1495)): it finishes its own setup before your program's `Main` runs, so it can't hold up the debugger's evaluations at a stop just after the start.
- **Move type to X.cs makes a file you can use** ([#1528](https://github.com/Zaneris/passenger/issues/1528)): the new file was missing from the Explorer, and every use of the type was an error until Passenger restarted.
- **Fix name violation renames the file with the type** ([#1494](https://github.com/Zaneris/passenger/issues/1494)), and Rename file works when only the letter case changes.
- **Configuration warnings in a library check the programs that run it** ([#1525](https://github.com/Zaneris/passenger/issues/1525)): a key your web API's `appsettings.json` gives is no longer flagged in the library that reads it.
- **Problems matches the editor for multi-targeted projects** ([#1475](https://github.com/Zaneris/passenger/issues/1475)): solution-wide analysis takes each one once, in the framework you chose, and the status bar shows it at work where it said "no errors" before it had looked.
- **Update All under central package management finishes** ([#1479](https://github.com/Zaneris/passenger/issues/1479)): it stopped partway on its own write. A version kept in a property now moves the property ([#1483](https://github.com/Zaneris/passenger/issues/1483)), and `Directory.Packages.props` keeps its blank lines and final newline ([#1484](https://github.com/Zaneris/passenger/issues/1484)).
- **EF Core's packages update as one set** ([#1493](https://github.com/Zaneris/passenger/issues/1493)) in the NuGet window, Update All and the Migrations window.
- **Terminal tabs keep to themselves** ([#1487](https://github.com/Zaneris/passenger/issues/1487)): a program started in one tab could type into another, and a tab's shell could outlive Passenger.
- **Shift+Enter and Ctrl+Enter reach terminal programs that ask for them** ([#1477](https://github.com/Zaneris/passenger/issues/1477)), so a TUI such as OpenCode can take a newline.
- **One test project that can't start no longer hides the others' tests** ([#1515](https://github.com/Zaneris/passenger/issues/1515)): the Unit Tests window says which one it was and why, and a test project the solution builds for a platform of its own (`bin/x64`) runs too.
- **The Git log's branch buttons grey where they can't act** ([#1532](https://github.com/Zaneris/passenger/issues/1532)), saying why, where Update Selected did nothing on a remote's branch.
- **Agents' answers right after a change that made a file** ([#1535](https://github.com/Zaneris/passenger/issues/1535)): diagnostics, definition and the rest wait until the new file is part of the project, so they no longer report a type that just moved as missing.
- **Soft wrap on long lines can't overflow the stack** ([#1516](https://github.com/Zaneris/passenger/issues/1516)), which could end Passenger on a busy machine.
- **Linux: Type1 fonts are measured** ([#1497](https://github.com/Zaneris/passenger/issues/1497)), such as Ubuntu's URW faces, where they raised an error as Passenger looked for monospaced fonts.
- **Windows: stopping a program ends everything it started** ([#1504](https://github.com/Zaneris/passenger/issues/1504)), including a process it was starting at that moment.
- **Windows: Cut and Paste into a new folder in the Explorer** ([#1501](https://github.com/Zaneris/passenger/issues/1501)) keeps the folder's row, where it built the row again.

## Lighter as you work

- **Debugger answers and test results cost less memory to read** ([#1510](https://github.com/Zaneris/passenger/issues/1510), [#1506](https://github.com/Zaneris/passenger/issues/1506)), on a busy machine as on an idle one.
- **A stylesheet or JSON schema from the web downloads once** ([#1505](https://github.com/Zaneris/passenger/issues/1505)), however many files ask for it at the same moment.
- **The C# language server's health check stays quiet** ([#1482](https://github.com/Zaneris/passenger/issues/1482)): on macOS and Linux each check left a stray loose file in the server, and on Windows its log took an error at every check.
