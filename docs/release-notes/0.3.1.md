Passenger 0.3.1 fixes the editor drawing lines you had deleted, which could hide what you typed until you switched tabs, and makes 0.3.0 sturdier everywhere you lean on it: C# 15 reads as .NET 11 ships it, no file however deeply it nests can take Passenger down with your unsaved work, a screen reader hears every control, Arabic, Hebrew and other scripts take your system's own fonts, and Passenger holds less memory as you work. The NuGet window gains an Updates tab that brings every package up to date in one step. It fixes dozens of bugs besides, in the debugger, Hot Reload, the profiler, Godot, containers and NuGet. It is still free and open source under MIT, and everything it closed is in its [0.3.1 milestone](https://github.com/Zaneris/passenger/milestone/8).

## Highlights

- **Deleted lines no longer stay drawn in the editor** ([#1423](https://github.com/Zaneris/passenger/issues/1423), [#1422](https://github.com/Zaneris/passenger/issues/1422)): after Select All and Delete, lines selected and deleted or cut, or Backspace at a line's start, the old lines could stay on screen over what the file now held, hiding what you typed until you switched tabs. Each case is now held, pixel for pixel, to what a freshly opened editor draws.
- **Update every package at once** ([#1438](https://github.com/Zaneris/passenger/pull/1438)): the NuGet window's Updates tab lists each installed package with a newer version, installed → latest, and Update All moves them across your projects as one step of Undo, keeping exact pins and central versions, stopping if you edit a project file meanwhile, and saying which feeds could not be checked.
- **C# 15 as .NET 11 ships it** ([#1352](https://github.com/Zaneris/passenger/issues/1352)): code using C# 15's finished features, such as a collection expression's arguments (`[with(StringComparer.OrdinalIgnoreCase)]`), no longer shows as an error calling the feature a preview. Passenger now carries a newer C# language server.
- **Arabic, Hebrew and other scripts take your system's own fonts** ([#1426](https://github.com/Zaneris/passenger/issues/1426)): text the code font lacks, in code, the terminal and popups, is drawn in the font Windows, macOS or Linux gives it, where it could come out in whichever installed font came first by name: for one reporter on Windows, a tiny calligraphic one.
- **No text can end Passenger** ([#1308](https://github.com/Zaneris/passenger/issues/1308), [#1353](https://github.com/Zaneris/passenger/issues/1353), [#1361](https://github.com/Zaneris/passenger/issues/1361), [#1376](https://github.com/Zaneris/passenger/issues/1376)): a C#, XAML, JSON, Markdown, SVG or project file, a Godot scene, a nuget.config or a template nested thousands deep opens and says where it goes too deep, where opening it could end the IDE and take everything unsaved with it.
- **Screen readers hear every button, field and row by name** ([#1282](https://github.com/Zaneris/passenger/issues/1282)), on Windows, macOS and Linux.
- **GDScript completion offers what Godot accepts where you type** ([#1301](https://github.com/Zaneris/passenger/issues/1301)): a local only inside its block, a class's own members after its name, `new`, engine enums, what a bracket closes, and in a static function only what needs no instance.
- **Several Godot games in one folder** ([#1393](https://github.com/Zaneris/passenger/issues/1393), [#1373](https://github.com/Zaneris/passenger/issues/1373)): each game's Godot editor connects, so Passenger never writes over a scene any of them holds unsaved, and an error's stack opens its own game's scripts.
- **Apps at a `*.localhost` name are this machine's** ([#1395](https://github.com/Zaneris/passenger/issues/1395), [#1406](https://github.com/Zaneris/passenger/issues/1406)): an app made with `dotnet new webapi --localhost-tld` gets its OpenAPI document read, browser refresh under debug and its AppHost's dashboard, and requests to this machine skip a proxy set in the environment.

## Fixed

### Godot

- **GoDotTest imports a game never opened in Godot before its tests run** ([#1394](https://github.com/Zaneris/passenger/issues/1394)), and Run imports a GDScript game only when a class's name or base changed, never after every edit.
- **A paused GDScript's vectors read as written** ([#1370](https://github.com/Zaneris/passenger/issues/1370)): `(0.3, 0.1)`, not `(0.30000001192092896, …)`, and PackedStringArray, node and resource exports edit as their types in the scene's inspector.
- **GDScript's language server finds your running Godot editor** by your Godot version's settings ([#1371](https://github.com/Zaneris/passenger/issues/1371)), on a machine that ran Godot 4.2 before 4.3 and for a self-contained Godot.
- **A name written with an escape** (`"caf\u00e9"`) is found by Go to Declaration and Find Usages, and completion works after a raw string ending in a backslash ([#1374](https://github.com/Zaneris/passenger/issues/1374)).
- **A shader uniform declared in an `#include`** goes to its declaration and renames with the materials that set it, and a project named with escapes shows its real name ([#1372](https://github.com/Zaneris/passenger/issues/1372)).
- **Rarer paths** ([#1302](https://github.com/Zaneris/passenger/issues/1302)): an agent's clicks and keys reach a game's second window, the resource picker offers only files that load as the property's class, theme items follow the project's Godot version, and a configuration named `Arena #2` is its own game.
- **A .NET project beside a Godot game, such as a 2dog host, runs as the .NET program it is** ([#1414](https://github.com/Zaneris/passenger/issues/1414)): Run, Debug and its configurations no longer take it for a game Godot runs.
- **Godot is found through `GODOT4` too** ([#1413](https://github.com/Zaneris/passenger/issues/1413)), the variable Godot's C# guide names, where `GODOT` isn't set, and a launch profile running `%GODOT4%` runs the game.
- **The GDScript server's Godot starts again on another port** where Windows gave its port to another program first ([#1356](https://github.com/Zaneris/passenger/issues/1356)).

### Debugging, Hot Reload and profiling

- **Run, Debug and Profile start your app through its own executable, as `dotnet run` does** ([#1416](https://github.com/Zaneris/passenger/issues/1416)): on Windows its manifest (DPI awareness, common controls, long paths), icon and process name now apply, still on the .NET Passenger builds with.
- **A step from a program paused in a sleep, a wait or a read comes back as the call returns** ([#1359](https://github.com/Zaneris/passenger/issues/1359), [#1362](https://github.com/Zaneris/passenger/issues/1362)), with Just My Code on or off.
- **Smart Step Into in a deeply nested file no longer ends the debugger**, and a condition or watch nested too deep is refused saying why ([#1376](https://github.com/Zaneris/passenger/issues/1376)).
- **`[DebuggerDisplay]` and type proxies reach the generic construction they name** ([#1303](https://github.com/Zaneris/passenger/issues/1303)), and Hot Reload reaches a plugin loaded twice.
- **WPF's XAML Hot Reload clears `Grid.Row`** and any attached property taken off a root ([#1390](https://github.com/Zaneris/passenger/issues/1390)).
- **A crashed program's end names its signal**, "exit code 139 (SIGSEGV)", wherever an exit code is told ([#1396](https://github.com/Zaneris/passenger/issues/1396)).
- **A .NET 10 program still starting no longer hangs** when the Stats tab, the Requests window or an agent reads it live ([#1340](https://github.com/Zaneris/passenger/issues/1340)).
- **A memory snapshot of a program that ends during it is kept** ([#1386](https://github.com/Zaneris/passenger/issues/1386)), and a held program whose diagnostic port fails is said in words, not thrown ([#1388](https://github.com/Zaneris/passenger/issues/1388)).
- **The profiler's Frames page keeps its rows in view** in a short bottom pane ([#1329](https://github.com/Zaneris/passenger/issues/1329)): what is written above the chart scrolls, where it could take the whole page and leave the table no room.
- **A browser debug session no longer holds up to 64 MB** for the rest of the session after one large DevTools message ([#1389](https://github.com/Zaneris/passenger/issues/1389)).

### Editing

- **A terminal that closes on Windows can no longer end Passenger**: a read of its pseudo-terminal closed meanwhile, which Windows refuses as access denied, went unhandled on the terminal's own thread.
- **Hover cards keep a doc comment's backslashes and stars** (`C:\temp`, not `C:temp`), and plain-text hovers show as written ([#1380](https://github.com/Zaneris/passenger/issues/1380), [#1405](https://github.com/Zaneris/passenger/issues/1405)).
- **Convert Indentation works on Python again**, never turning a file that loads into one that doesn't ([#1309](https://github.com/Zaneris/passenger/issues/1309), [#1354](https://github.com/Zaneris/passenger/issues/1354), [#1362](https://github.com/Zaneris/passenger/issues/1362)).
- **A long chain no longer holds the window** in Extend Selection, Surround With or a breakpoint's hover ([#1353](https://github.com/Zaneris/passenger/issues/1353), [#1301](https://github.com/Zaneris/passenger/issues/1301)).
- **Go to Declaration in a .props or .targets file** with lone carriage returns lands on the right line ([#1380](https://github.com/Zaneris/passenger/issues/1380)).
- **An .editorconfig value with a comment after it** (`max_line_length = off  # no wrap`) takes effect ([#1383](https://github.com/Zaneris/passenger/issues/1383)).
- **A C# file outside every project, beside one, keeps the language server's colours** ([#1352](https://github.com/Zaneris/passenger/issues/1352)), and a C# 15 `union` at `LangVersion` latest reads as one before the server answers.
- **Change Signature given a type nested too deep says so**, where it could end the C# language server ([#1403](https://github.com/Zaneris/passenger/issues/1403)).

### Projects, files and NuGet

- **New Solution and New Project follow the SDK of the directory you choose** ([#1368](https://github.com/Zaneris/passenger/issues/1368)), and say why only .sln is offered where that SDK makes no .slnx.
- **A `Bin` or `Obj` folder in another letter case is left out** of Go to File and Find in Files on macOS and Windows, and a changed `.proj` reloads the solution ([#1377](https://github.com/Zaneris/passenger/issues/1377)).
- **A target framework in capitals** (`NET8.0-windows`) gets its XAML preview, Hot Reload and container image ([#1378](https://github.com/Zaneris/passenger/issues/1378)).
- **Editing a NuGet feed's credentials no longer duplicates them** where nuget.config writes them in another letter case ([#1387](https://github.com/Zaneris/passenger/issues/1387)).
- **A folder renamed, moved or deleted lets go of its builds first** on Windows, and so do Undo and Redo of a move ([#1358](https://github.com/Zaneris/passenger/issues/1358), [#1362](https://github.com/Zaneris/passenger/issues/1362), [#1363](https://github.com/Zaneris/passenger/issues/1363)).
- **The Commit window no longer draws over its own form** in a short column, and scrolls when it's shorter than its form ([#1369](https://github.com/Zaneris/passenger/issues/1369)).
- **A large tree copied, unpacked or moved into the open folder no longer has Local History read and keep every file** ([#1365](https://github.com/Zaneris/passenger/issues/1365)): files arriving in bulk are passed over until you open, save or change one, while a file it already knows that another program changed is still kept.
- **A deleted file is struck through, and a long folder ends in an ellipsis, in every list of changed files** ([#1379](https://github.com/Zaneris/passenger/issues/1379)): Commit, a commit's files in the Git log, Show Diff with Working Tree and Local History.
- **Install .NET SDK on Windows no longer waits minutes** for a virus scanner reading the files it just unpacked ([#1364](https://github.com/Zaneris/passenger/issues/1364)), and a failed first run says its exit code and first line ([#1404](https://github.com/Zaneris/passenger/issues/1404)).

### Containers, Aspire and deploys

- **A Testcontainers project's tests run on Windows with Docker Desktop** ([#1430](https://github.com/Zaneris/passenger/issues/1430)), where they failed before any test ran with "The endpoint is not a npipe URI".
- **A container push to a registry that asks for no login goes on** ([#1310](https://github.com/Zaneris/passenger/issues/1310)), and a Windows container profile publishes ([#1303](https://github.com/Zaneris/passenger/issues/1303)).
- **A kubeconfig written as JSON is read** for a deploy step ([#1303](https://github.com/Zaneris/passenger/issues/1303)).
- **An AppHost whose port another program took is started again on another** ([#1356](https://github.com/Zaneris/passenger/issues/1356)).
- **A container's log under Podman no longer shows its compose warning**, and an image at registry.hub.docker.com opens its Docker Hub page ([#1399](https://github.com/Zaneris/passenger/issues/1399)).
- **A container, Aspire or package command that fails partway** (a broken pipe, more output than is read, a limit passed) is reported as that command's failure everywhere, where some places showed it as an IDE error ([#1397](https://github.com/Zaneris/passenger/issues/1397)).

## Lighter as you work

- **Code previews let go when they close** ([#1428](https://github.com/Zaneris/passenger/issues/1428)): Find in Files' preview, Recent Locations and other read-only code views stayed in memory after closing, each waking the IDE twice a second and adding to it with every search. Opening another folder in a window lets go of the one before, a closed diff tab keeps 64 bytes where it kept the compared texts and its file, an app's OpenAPI documents are let go once read, and Settings' font list no longer keeps every installed font loaded (about 10 MB on a Mac).
- **Git's status costs about half the memory it did** ([#1429](https://github.com/Zaneris/passenger/issues/1429)), read after every save and change on disk, and nothing for the folders above each untracked file, so a folder of thousands of untracked files no longer churns memory on every refresh.
- **A running app's picture costs its own size** ([#1429](https://github.com/Zaneris/passenger/issues/1429)): an agent's `app_screenshot`, the Live Visual Tree and the WPF preview read each frame without copying it into text first, where it cost three to four times the picture.
- **Files are read once** ([#1429](https://github.com/Zaneris/passenger/issues/1429)): opening a file, taking in a change made on disk, and Local History keeping a version each read the file into one array, where a 2 MB file cost 6 MB.
- **The Markdown preview keeps up with long files** ([#1429](https://github.com/Zaneris/passenger/issues/1429)): a pause in typing reads again only the lines around the edit, so a 1 MB file costs about 200 KB a pause where it cost 14 MB and 18 ms.
- **Typing in large files** ([#1427](https://github.com/Zaneris/passenger/issues/1427)): a key that adds or removes a foldable block in a large XML, XAML, JSON or C# file no longer copies the file's whole fold list, and on macOS and Linux the folder watcher makes no new string for most changes it hears, and a line of a program's output costs about the line itself.
- **The C# language server lets go of what's gone** ([#1428](https://github.com/Zaneris/passenger/issues/1428)): Godot, localization and Aspire data kept for files and projects you deleted or reloaded.
