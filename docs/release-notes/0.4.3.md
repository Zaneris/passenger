Passenger 0.4.3 goes where you go. Every release now comes as a portable build as well: unpack it anywhere, a USB stick included, and with a folder named `data` beside it, that copy keeps all its settings there and nothing anywhere else. New Solution starts your code as a Git repository whose line endings stay LF on every system, and Passenger now reads `.editorconfig`, `.gitattributes` and `.gitignore` as Roslyn and Git do, completing, explaining and checking what you write in them. Reformat Code, Code Cleanup and Optimize Imports run over a whole folder, project or solution from the Explorer, with `dotnet format` if you prefer it; the web languages run on Bun or Deno and check and format with Oxlint, Oxfmt and Biome; and the .NET and Avalonia tools Passenger runs for you no longer send usage data. It runs on Avalonia 12.2, and fixes the debugger's async lambdas and anonymous types, a WPF build run outside Passenger, moves in Git and more. It is still free and open source under MIT, and everything it closed is in its [0.4.3 milestone](https://github.com/Zaneris/passenger/milestone/17).

## Highlights

- **Portable Passenger** ([#2153](https://github.com/Zaneris/passenger/issues/2153)): every release now has a portable build for each system: `Passenger-windows-x64-portable.zip` and `Passenger-windows-arm64-portable.zip`, the Mac's app in `Passenger-macos-arm64.zip` and `Passenger-macos-x64.zip`, and Linux's archive. Unpack it anywhere, make a folder named `data` beside the app, and that copy keeps its settings, layouts, trusted folders and history there, writes nothing to your own folders or the system's recent lists, and tells you when a release is out without replacing itself.
- **New solutions start as Git repositories** ([#2141](https://github.com/Zaneris/passenger/issues/2141)): New Solution makes your solution's folder a repository with a `.gitignore` (.NET's, plus what Passenger's runs leave behind), a `.gitattributes` that keeps LF line endings on every system and marks binaries, and an `.editorconfig` set to LF, UTF-8 and a final newline. Each is a tick box, remembered for next time, and a solution made inside a repository simply joins it.
- **`.editorconfig`, `.gitattributes` and `.gitignore`, understood** ([#2140](https://github.com/Zaneris/passenger/issues/2140)): an `.editorconfig` completes its keys and values from what Roslyn and your projects' analyzers actually read and flags what nothing reads; a `.gitignore` shows on hover exactly what each line ignores, as Git answers; a `.gitattributes` has colours, completion and checks; and the Explorer's Add menu makes any of the three.
- **Tidy a whole folder, project or solution** ([#2156](https://github.com/Zaneris/passenger/issues/2156)): Reformat Code, Code Cleanup and Optimize Imports run from the Explorer over the files, folder, project or solution you choose, as one step of Undo you can stop partway, and Settings › Editor › C# formatter can hand C#'s layout to the SDK's `dotnet format`.
- **Bun, Deno, Oxlint, Oxfmt and Biome** ([#2157](https://github.com/Zaneris/passenger/issues/2157), [#2158](https://github.com/Zaneris/passenger/issues/2158)): the JavaScript, TypeScript and web language servers, ESLint and Prettier run on Bun or Deno where your folder uses them, with no Node.js needed, and a folder that uses Oxlint, Oxfmt or Biome gets their problems as you type, their fixes, and their layout on Reformat Code and on save.
- **No usage data from the tools Passenger runs** ([#2159](https://github.com/Zaneris/passenger/issues/2159), [#2170](https://github.com/Zaneris/passenger/issues/2170)): builds, restores, `dotnet watch`, `dotnet new`, `dotnet ef`, test runs, Aspire's CLI, `func start` and the Godot editors Passenger starts now run with each tool's telemetry turned off, unless you set it yourself. Your own programs and the Terminal keep your environment as it is.
- **Avalonia 12.2**: Passenger runs on Avalonia 12.2, with its fixes: two-finger scrolling with Linux's synaptics touchpad driver, a paste on Windows that waits out another program holding the clipboard, and Linux windows that no longer snap back to an earlier size. Your own apps on 12.2 are followed too: Go to Declaration reaches Fluent 12.2's control themes, and the Live Visual Tree and the debugger name a compiled binding again.
- **Tabs that read right in Cubicle** ([#2139](https://github.com/Zaneris/passenger/issues/2139)): under titled tabs, Cubicle's look, a tool window's tabs along its foot belong plainly to that window, and the tabs down the window's sides stand apart, the chosen mark beside their names rather than across them, in every theme.

## Formatting and code style

- **Over whatever you choose** ([#2156](https://github.com/Zaneris/passenger/issues/2156)): the Explorer's Code menu runs Reformat Code, Code Cleanup and Optimize Imports over a file, several chosen together, a folder, a project, a solution folder's projects or the whole solution, and the same keys and Find Action do it while the Explorer has the keys. Each file is laid out by its own language's formatter and its `.editorconfig`; read-only and generated files are left alone and counted, and the run says what it came to ("Reformat Code changed 2 of the 2 files of Models").
- **`dotnet format`, if you prefer** ([#2156](https://github.com/Zaneris/passenger/issues/2156)): Settings › Editor › C# formatter chooses Passenger's own formatter, the default, or the SDK's `dotnet format` for Reformat Code, Code Cleanup and Reformat on save, each file keeping its own line breaks and one Undo taking it all back.
- **An `.editorconfig` that knows your projects** ([#2140](https://github.com/Zaneris/passenger/issues/2140)): completion lists a section's globs by your files, every C# option Roslyn reads and a `dotnet_diagnostic` severity for each diagnostic your analyzers report; the hover card says what a key does, the values it takes, its default and what files a glob matches; and a key nothing reads, or a value its key doesn't take, is marked.
- **Agents tidy as you do** ([#2156](https://github.com/Zaneris/passenger/issues/2156)): an agent's Optimize Imports and Code Cleanup over a project or the solution take the same path, the open files in its one step of Undo and generated code left alone.

## Git

- **A `.gitignore` read as Git reads it** ([#2140](https://github.com/Zaneris/passenger/issues/2140)): completion lists your untracked folders and files and a pattern for each kind among them (`*.log`); hover says what a line ignores, or a `!` line keeps, and which tracked files it matches, which Git never ignores; a line that ignores nothing fades, and one a later `!` line wholly takes back is marked.
- **Add to .gitignore and Go to Ignoring Line** ([#2140](https://github.com/Zaneris/passenger/issues/2140)) from the Explorer's Git menu: add an unversioned file or folder, or open the line that decides whether a path is ignored.
- **A `.gitattributes` with help** ([#2140](https://github.com/Zaneris/passenger/issues/2140)): its attributes, Git's and GitHub Linguist's, complete with their values and the diff, merge and filter drivers your repository declares, each explained on hover, and an `eol` Git doesn't take or a driver nothing declares is marked.

## Web languages

- **Bun or Deno, as your folder uses** ([#2157](https://github.com/Zaneris/passenger/issues/2157)): a folder with Bun's lockfile runs the web language servers, ESLint and Prettier on Bun, one with a `deno.lock` on Deno, and Settings › Node.js › Runtime chooses whatever the lockfile says. A runtime that isn't installed is named in the file's banner, with where to get it.
- **Yarn Plug'n'Play** ([#2157](https://github.com/Zaneris/passenger/issues/2157)): a PnP project's ESLint, Prettier and TypeScript are found through its `.pnp.cjs`, with no `node_modules` anywhere, and the banner over a missing package runs your folder's own package manager, npm, pnpm, Yarn or Bun.
- **Oxlint, Oxfmt and Biome** ([#2158](https://github.com/Zaneris/passenger/issues/2158)): wherever your configuration or `package.json` names one, its problems show as you type and in Problems with a link to their rule, its fixes come first in Show Context Actions, and Oxfmt or Biome lays the file out on Reformat Code and on save, each run from the package your folder installs.

## Portable and installed copies

- **A portable copy updates by your hand** ([#2153](https://github.com/Zaneris/passenger/issues/2153)): it says a release is out, links its page and names the portable build to put in its place, downloading nothing.
- **A copy your package manager installed says so** ([#2153](https://github.com/Zaneris/passenger/issues/2153)): one WinGet unpacked, or one a package marked with a `package-manager` file beside it, names the command that updates it, and leaves its updates to that manager.

## Fixed

### The debugger

- **An async method's captured variables show** ([#2132](https://github.com/Zaneris/passenger/issues/2132), [#2133](https://github.com/Zaneris/passenger/issues/2133)): a variable a block of an async method captures in a lambda shows in Variables, the hover card and an agent's `debug_state`, and a stop in an async Main or other static async method whose lambda captures a block's variable shows the stop's variables, where it showed none.
- **Anonymous types evaluate** ([#2136](https://github.com/Zaneris/passenger/issues/2136)): `new { A = 1 }` shows `{ A = 1 }`, and `items.Select(i => new { i.Name }).ToList()` answers as your program would, where it was refused in the debugger's own words.
- **Arrays of object or of an interface evaluate** ([#2134](https://github.com/Zaneris/passenger/issues/2134)): `new object[] { 1, "two" }`, `new IComparable[2]` and LINQ over interfaces, GroupBy and Cast among them, answer, where they failed with a BadImageFormatException.
- **A program `dotnet watch` runs is named dotnet** ([#2137](https://github.com/Zaneris/passenger/issues/2137)) in Attach to Process and to agents, where it took the name of its startup hook.

### The editor and C#

- **Overloads fit as C# says they do** ([#2126](https://github.com/Zaneris/passenger/issues/2126), [#2127](https://github.com/Zaneris/passenger/issues/2127), [#2129](https://github.com/Zaneris/passenger/issues/2129)): Parameter Info and completion's cards no longer set back an overload your arguments fit as C# converts them (`Math.Max(1, 2)` fits its byte overload too), a card lists at most eight overloads and says how many more so their documentation stays in sight, and Parameter Info comes back to the outer call as a nested one closes.
- **The navigation bar comes as soon as a file declares something** ([#2125](https://github.com/Zaneris/passenger/issues/2125)), a new or emptied file included, and Jump to Navigation Bar in a file that declares nothing says so ([#2130](https://github.com/Zaneris/passenger/issues/2130)), where it did nothing.
- **A JSON key is no heading** ([#2128](https://github.com/Zaneris/passenger/issues/2128)): a key whose value is a string no longer wears a Markdown heading's badge in the navigation bar, File Structure and Go to Symbol, nor is read to a screen reader as a heading.
- **The Find window follows a file renamed or moved** ([#2148](https://github.com/Zaneris/passenger/issues/2148)): its results open the file where it is now and keep following your edits.
- **The diff's note of line separators tells true** ([#2150](https://github.com/Zaneris/passenger/issues/2150)): lines added after a last line with no line break no longer read as "LF added at the end".

### Git and the Explorer

- **Unstaging a moved file keeps the move** ([#2143](https://github.com/Zaneris/passenger/issues/2143)), where the old name came back as deleted and the new one as unversioned.
- **Delete takes a file's nested files with it** ([#2144](https://github.com/Zaneris/passenger/issues/2144)): Form1.cs its Form1.Designer.cs and Form1.resx, Counter.razor its Counter.razor.cs and Counter.razor.css, the question saying how many go and one Undo bringing them all back.
- **The Commit window's rows name the right folder** ([#2146](https://github.com/Zaneris/passenger/issues/2146)) when Group By › Directory turns while it shows.

### Building

- **A `dotnet build` outside Passenger runs undisturbed** ([#2121](https://github.com/Zaneris/passenger/issues/2121)): a WPF app built in a terminal while Passenger has its folder open no longer fails with BG1002 or restarts Passenger's C# language server, and Passenger's own design-time builds no longer delete the app's compiled XAML, so the next build doesn't compile all of it again.
- **Passenger's own solution loads in Visual Studio** ([#2123](https://github.com/Zaneris/passenger/issues/2123)), for anyone who builds it there.
- **On Windows a project's folder can be renamed, moved or deleted as the C# language server loads it** ([#2065](https://github.com/Zaneris/passenger/issues/2065), [#2138](https://github.com/Zaneris/passenger/issues/2138)): Passenger waits for the server's reads of it to end, where the move could fail with "Access to the path … is denied".

### The terminal

- **bash keeps your own PROMPT_COMMAND** ([#2131](https://github.com/Zaneris/passenger/issues/2131)): history, prompt themes and nested shells work beside Passenger's marks, where adding to it after a separator printed a syntax error at every prompt, a prompt's status read every command as succeeded, and a bash started inside said `__passenger_marks: command not found`.
- **zsh with `setopt nounset` in your `.zshenv`** ([#2135](https://github.com/Zaneris/passenger/issues/2135)) keeps Passenger's prompt marks and the folder's dotnet first on the PATH.

### Web requests and profiling

- **Visual Studio's private environments** ([#2155](https://github.com/Zaneris/passenger/issues/2155)): an `.http` file's requests read `http-client.env.json.user` beside JetBrains' private file, and it opens as JSON, coloured and checked.
- **An environment's own value wins** ([#2151](https://github.com/Zaneris/passenger/issues/2151)) over every file's `$shared`, as Visual Studio's documentation of `.http` files says.
- **A request written into an open `.http` file keeps its line endings** ([#2147](https://github.com/Zaneris/passenger/issues/2147)), CRLF included.
- **The Requests window says times as every number** ([#2152](https://github.com/Zaneris/passenger/issues/2152)): "1,234 ms".
- **A memory snapshot can't wait forever** ([#2117](https://github.com/Zaneris/passenger/issues/2117)): each step has a limit, and a snapshot that stops says which step it stopped at, in the status bar and to an agent.

### Avalonia apps and mobile

- **Bindings named again in apps on Avalonia 12.2**: Break When Value Changes says a value changed "by its binding Caption", and the Properties page and a XAML file's binding values while debugging name the binding behind a value.
- **An iOS app's install on a simulator waits as long as it takes**, where one still going after 3 minutes on a slow or busy Mac was refused.

### Agents

- **find_in_files and replace_in_files keep to the directory or project given** ([#2142](https://github.com/Zaneris/passenger/issues/2142)), where they searched, and replaced, across the whole solution.
- **vcs_status's diffs apply with git apply** ([#2149](https://github.com/Zaneris/passenger/issues/2149), [#2154](https://github.com/Zaneris/passenger/issues/2154)): a new or deleted file's diff runs from or to `/dev/null`, a last line with no line break carries Git's `\ No newline at end of file`, and a CRLF file's lines keep their CRs where Git stores them so.

## Lighter as you work

- **Staging hundreds of files is near-instant** ([#2145](https://github.com/Zaneris/passenger/issues/2145)): 600 files took 25 s to stage on a Mac and now take a fraction of a second, Undo and Redo included.
