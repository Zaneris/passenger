Passenger 0.4.6 runs your .NET 11 device tests where they belong: on an Android device or emulator, an iOS simulator or the Mac itself, each result in the Tests window, and Debug Unit Tests stops at your breakpoints there. It is quicker and lighter where you feel it, opening Settings, typing in C#, loading a large solution, reading .NET's folders on macOS and sitting idle, and it no longer fills your temporary folder. A double Shift opens Go to Everything in every keymap, bookmarks can be numbered, folds open and close by level, and Find Word at Caret and zoom for the whole window are a key away. It keeps up with Aspire 17, NuGet 8's minimum publish age and .NET 11's runtime async, and Vim mode does what Vim does in many more cases. It is still free and open source under MIT, and everything it closed is in its [0.4.6 milestone](https://github.com/Zaneris/passenger/milestone/21).

**Updating on Windows:** If the update to 0.4.6 doesn't install, choose Restart to Update again or run the installer from this page; from 0.4.6 on, updates retry by themselves.

## Highlights

- **Device tests where they run** ([#2338](https://github.com/Zaneris/passenger/issues/2338)): a .NET 11 `androidtest`, `iostest` or `maccatalysttest` project's tests run on the device, emulator, simulator or Mac chosen beside its run configuration, as its app would, where they ran on this machine and failed. Debug Unit Tests stops at a breakpoint in a test there, its locals shown. And an app on an iOS simulator now gets its run configuration's arguments ([#2352](https://github.com/Zaneris/passenger/issues/2352)).
- **Quicker and lighter** ([#2346](https://github.com/Zaneris/passenger/issues/2346), [#2347](https://github.com/Zaneris/passenger/issues/2347), [#2348](https://github.com/Zaneris/passenger/issues/2348), [#2349](https://github.com/Zaneris/passenger/issues/2349), [#2357](https://github.com/Zaneris/passenger/issues/2357), [#2358](https://github.com/Zaneris/passenger/issues/2358), [#2359](https://github.com/Zaneris/passenger/issues/2359), [#2360](https://github.com/Zaneris/passenger/issues/2360)): Settings opens without searching the disk and its theme list stays quick however many themes you keep, a large solution loads without churning tens of megabytes, a key in a C# file allocates nothing to find its colours or its project, macOS reads the root-owned .NET install in a fraction of the time, and an idle Passenger does next to nothing.
- **A clean temporary folder** ([#2373](https://github.com/Zaneris/passenger/issues/2373)): the .NET SDK commands Passenger runs that build nothing, and the MSBuild that reads your projects, work in a folder of Passenger's own, removed however Passenger ends, where each left an empty folder behind for good.
- **Updates on Windows retry by themselves** ([#2300](https://github.com/Zaneris/passenger/issues/2300)): where Update.exe is refused because something still holds the install's folder, Passenger applies the update again as it closes, up to three tries in all, and if it still doesn't install, the next start says Update.exe's own reason.
- **Keys you already know** ([#2301](https://github.com/Zaneris/passenger/issues/2301), [#2313](https://github.com/Zaneris/passenger/issues/2313), [#2312](https://github.com/Zaneris/passenger/issues/2312), [#2318](https://github.com/Zaneris/passenger/issues/2318), [#2315](https://github.com/Zaneris/passenger/issues/2315)): a double Shift opens Go to Everything in the Visual Studio and VS Code keymaps too, Ctrl+Shift+0 to Ctrl+Shift+9 set numbered bookmarks (all but Ctrl+Shift+5 in the VS Code keymaps), folds open and close recursively or to a level, and Find Word at Caret, Find in Selection, Zoom In and Out, Full Screen and Hide Side Windows each have their keys.
- **Async call stacks on .NET 11** ([#2339](https://github.com/Zaneris/passenger/issues/2339)): stopped in a method compiled with .NET 11's runtime async after an await, the Call Stack lists the methods awaiting it, each at its await, as it does for the same code compiled with state machines.
- **Aspire 17** ([#2324](https://github.com/Zaneris/passenger/issues/2324), [#2327](https://github.com/Zaneris/passenger/issues/2327)): a new AppHost and Add Aspire Orchestration write Aspire 17's own form, a plain .NET project adding its services by path, and every way an AppHost adds a .NET service is read, `AddCSharpApp` too.
- **NuGet 8's minimum publish age** ([#2335](https://github.com/Zaneris/passenger/issues/2335), [#2341](https://github.com/Zaneris/passenger/issues/2341)): with `minPublishAgeHours` in your `nuget.config`, the NuGet window, Update All, EF Core's provider moves and your agent's installs take only versions old enough, a newer one tagged as held back, saying when it was published.

## Mobile and devices

- **Android test projects, on the device** ([#2338](https://github.com/Zaneris/passenger/issues/2338)): Run Tests installs the app where its project runs, starting an emulator if none runs, and runs its instrumentation there. Each test's result comes as it ends, then again with its time, message and stack. The template's instrumentation runs every test of the app, whichever you chose.
- **iOS and Mac Catalyst test projects** ([#2338](https://github.com/Zaneris/passenger/issues/2338)): an `iostest` project's tests run on the iOS simulator chosen beside its run configuration, booted for the run if it was shut down, and a `maccatalysttest` project's in its app on this Mac, out of sight. Stop ends the app there.
- **Debug a device test** ([#2338](https://github.com/Zaneris/passenger/issues/2338)): Debug Unit Tests starts the test app under Passenger's own debugger on Android, an iOS simulator or Mac Catalyst, stops at your breakpoints, and shows the results as Run Tests does.
- **Arguments on an iOS simulator** ([#2352](https://github.com/Zaneris/passenger/issues/2352)): a run configuration's arguments reach the app's `Main` as they do on the desktop, an argument in quotes kept whole.

## Faster and lighter

- **Settings opens at once** ([#2347](https://github.com/Zaneris/passenger/issues/2347), [#2348](https://github.com/Zaneris/passenger/issues/2348)): it no longer searches your PATH and Applications for Godot before it draws, about 120 ms at every open, and its theme and colour scheme lists come from themes read in the background: with 40 themes kept, a list made again allocates 70 KB, where it allocated 11.7 MB.
- **Large solutions load lighter** ([#2349](https://github.com/Zaneris/passenger/issues/2349)): the language server's 867 file watches for Passenger's own solution allocate about 69 KB as they come in, where they allocated 42 MB.
- **Typing in C#** ([#2357](https://github.com/Zaneris/passenger/issues/2357), [#2358](https://github.com/Zaneris/passenger/issues/2358)): a key no longer allocates to look for colours in a file that names none, nor to find the file's project, however many projects your solution has.
- **.NET's folders on macOS** ([#2346](https://github.com/Zaneris/passenger/issues/2346)): reading the root-owned `/usr/local/share/dotnet/packs`, as the language server's watch does, takes about 300 ms where it took up to 1.5 s, and seconds under load.
- **An idle Passenger rests** ([#2359](https://github.com/Zaneris/passenger/issues/2359), [#2360](https://github.com/Zaneris/passenger/issues/2360)): its look each second for the .NET programs it started takes 0.27 ms and 500 bytes among 500 processes, where it took 1.15 ms and 174 KB, and on macOS its watcher's beat no longer syncs a file to disk every 2 seconds.

## Your temporary folder

- **Nothing left behind** ([#2373](https://github.com/Zaneris/passenger/issues/2373)): `dotnet new`, workload, solution and package commands, and the MSBuild that reads your projects, work in a folder of Passenger's own, removed however Passenger ends, a crash included, and a headless screenshot's own state takes its folders with it. A build keeps your own temporary folder, so its compiler server stays the one your terminal's builds share.

## Keys

- **Double Shift everywhere** ([#2301](https://github.com/Zaneris/passenger/issues/2301)): Go to Everything opens on a double Shift in the Visual Studio and VS Code keymaps on every system, as in IntelliJ IDEA's, and Ctrl+T (Cmd+T) still opens it. Every keymap was checked key by key and given the keys it lacked for actions Passenger has, such as Alt+2 for Bookmarks, Ctrl+Alt+F5 for Run Here and the Ctrl+U chords for tests in the Visual Studio keymaps.
- **Numbered bookmarks** ([#2313](https://github.com/Zaneris/passenger/issues/2313)): Ctrl+Shift+0 to Ctrl+Shift+9 set that digit's bookmark on the caret's line, or take it away there, in every keymap but for Ctrl+Shift+5 in the VS Code keymaps, and Ctrl+0 to Ctrl+9 go to it from any file in every keymap, with Ctrl on a Mac too. Its digit shows in the gutter and the Bookmarks window, and the folder keeps it.
- **Folds by level** ([#2312](https://github.com/Zaneris/passenger/issues/2312)): Expand Recursively and Collapse Recursively (Ctrl+Alt+= and Ctrl+Alt+-, Cmd+Option on a Mac) open or fold the region at the caret with everything inside it, and Expand to Level and Expand All to Level 1 to 5 (Ctrl+keypad \* or Ctrl+Shift+keypad \*, then the level) leave just that many levels open, under Code › Folding.
- **Find from the caret** ([#2318](https://github.com/Zaneris/passenger/issues/2318)): Find Word at Caret (Ctrl+F3, Cmd+F3) and Find Previous Word at Caret go to the next or previous copy of the word or selection, Find in Selection (the find bar's In selection, Alt+L) keeps the search and Replace All inside it, and Incremental Search (Ctrl+I, Cmd+I on a Mac, in the Visual Studio keymaps) opens the find bar empty, finding as you type.
- **The window from the keyboard** ([#2315](https://github.com/Zaneris/passenger/issues/2315)): Zoom In, Zoom Out and Reset Zoom step the whole window from 100% to 300%, and Full Screen, Hide Side Windows (Ctrl+B, Cmd+B on a Mac, in the VS Code keymaps), Jump to Last Tool Window, Close Tool Window Tab (Ctrl+Shift+F4) and Next and Previous Split each have their keymap's keys.

## .NET 11 and your platforms

- **Runtime async's callers** ([#2339](https://github.com/Zaneris/passenger/issues/2339)): the Call Stack of a resumed runtime-async method lists each method awaiting it at its await, a click away from its line, decompiled where it has no symbols.
- **C# 15 unions and extension blocks** ([#2332](https://github.com/Zaneris/passenger/issues/2332)): the navigation bar over the editor lists a union and an extension block's members, named as the compiler names them (`extension(Pet)`), and Recent Locations names a place in one.
- **File-based programs' directives with metadata** ([#2333](https://github.com/Zaneris/passenger/issues/2333)): `#:ref ./library.cs Aliases=Library` names `./library.cs`, as .NET 11's SDK reads it, and renaming or moving that file rewrites the directive with its metadata kept.
- **Aspire 17** ([#2324](https://github.com/Zaneris/passenger/issues/2324), [#2327](https://github.com/Zaneris/passenger/issues/2327)): New Project's AppHost and Add Aspire Orchestration write a plain `Microsoft.NET.Sdk` AppHost on Aspire 17's packages, adding services by path with `AddDotnetProject`, never the obsolete `Aspire.AppHost.Sdk` or `AddProject`, and `AddCSharpApp` is read beside them for Go to Declaration, the gutter's run icons and the services a run lists.
- **NuGet 8's minimum publish age** ([#2335](https://github.com/Zaneris/passenger/issues/2335), [#2341](https://github.com/Zaneris/passenger/issues/2341)): `minPublishAgeHours` and `minPublishAgeExceptions` hold back a version too new wherever Passenger picks or offers one: the Updates and Browse lists, Update All, a package's details, a vulnerable version's fix, EF Core's provider moves and `nuget_install`. A local folder's packages are dated by their files, as NuGet dates them.
- **OpenAPI 3.2** ([#2336](https://github.com/Zaneris/passenger/issues/2336)): a document's `QUERY` operations and its `additionalOperations` are listed in the Endpoints window, sent with their own method, and written by Generate Requests from OpenAPI.
- **Container images where your containers run** ([#2334](https://github.com/Zaneris/passenger/issues/2334)): a container publish loads its image into Docker or Podman, the engine Passenger runs, where .NET 11's SDK could load it into Apple's `container` or WSL's `wslc` if it found them first.

## Fixed

### C# and the editor

- **Documentation's bold, links and code in the cards** ([#2274](https://github.com/Zaneris/passenger/issues/2274)): hover, completion and Parameter Info draw a doc comment's bold, emphasis, underline, code and links, even where a generator wrote the tags escaped, where they showed raw.
- **Renaming a copied file renames only the copy** ([#2284](https://github.com/Zaneris/passenger/issues/2284)), with its class, from the Solution view or the editor, the original keeping its name, its class and its uses.
- **A Razor code block's scripts and styles are coloured** ([#2325](https://github.com/Zaneris/passenger/issues/2325)) as JavaScript and CSS before the language server answers.

### Git

- **A copied file diffs as new** ([#2287](https://github.com/Zaneris/passenger/issues/2287)): an unversioned file is compared with nothing, even at a name another file had before a rename was undone.

### The window

- **Settings' font lists open on Linux** ([#2291](https://github.com/Zaneris/passenger/issues/2291)) with a Type1 font installed, as Ubuntu installs Nimbus Mono PS: a font Passenger can't draw is no longer offered, and one named in `settings.json` is refused, saying why.
- **IDE Internal Errors resizes** ([#2293](https://github.com/Zaneris/passenger/issues/2293)) from its lower right corner, a long stack trace getting the room.
- **An empty folder shows no expand arrow in the Explorer** ([#2294](https://github.com/Zaneris/passenger/issues/2294)), gaining one as a file comes in and losing it as the last goes.
- **File icons follow a theme switch** ([#2296](https://github.com/Zaneris/passenger/issues/2296)) at once, in the Explorer, the editor tabs and every list of files.
- **A deeply nested SVG previews** ([#2322](https://github.com/Zaneris/passenger/issues/2322)), where reading it could run out of stack.
- **WPF Preview draws a library's XML namespaces** ([#2273](https://github.com/Zaneris/passenger/issues/2273)): `xmlns:i="http://schemas.microsoft.com/xaml/behaviors"` and its `i:Interaction.Triggers` preview as they run, a referenced project's library too.

### Updates on Windows

- **A refused update is tried again** ([#2300](https://github.com/Zaneris/passenger/issues/2300)): Passenger hands the update to Update.exe through a step of its own that runs it again while it is refused, three tries in all, then starts the version installed for Restart to Update.
- **The old version lets go sooner** ([#2300](https://github.com/Zaneris/passenger/issues/2300)): the version being replaced answers Update.exe's last call to it before anything else of it loads, so it holds the install's folder as briefly as it can.
- **Why an update didn't install** ([#2300](https://github.com/Zaneris/passenger/issues/2300)): the next start says Update.exe's own reason from Velopack's log, where it pointed to a log that didn't say.

### Vim mode

- **Sentences, `is` and `as`, as Vim takes them** (more of [#2224](https://github.com/Zaneris/passenger/issues/2224)): `is` and `as` with a count, after an operator such as `y` or carried on in a visual stretch, over line ends, empty lines, lines of blanks and the white ending the text take the stretch Vim 9.2 takes, held to Vim's own answers over hundreds of thousands of cases.
- **Marks through `J`** ([#2224](https://github.com/Zaneris/passenger/issues/2224)): a mark on a line `J` joins, an indented one too, stays on its character, and keeps its column through later edits, as Vim's does.
- **`j` and `k` after a motion that fails** ([#2270](https://github.com/Zaneris/passenger/issues/2270)): after an operator whose sentence, paragraph, word-back or search motion has nowhere to go, `j` and `k` keep to the cursor's own column, as in Vim.
- **A put over an emptied text** ([#2343](https://github.com/Zaneris/passenger/issues/2343)): a visual put of an empty register leaves the text empty and the registers as Vim leaves them.
