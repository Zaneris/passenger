Passenger 0.4.1 formats your C# as you type it: end a statement or close a block and it is laid out as Reformat Code would, your `.editorconfig` included, and one Undo takes it back. The `passenger-ide` command now opens Passenger from a terminal on Windows and macOS as on Linux, the Run and Debug windows show your program's colours, an address in a comment opens with a click, a double-clicked word lights its other places, the status bar shows your Git branch, web apps open in the browser you choose, and Aspire 17's AppHosts run. It also fixes dozens of things you could run into on 0.4.0, among them changes on disk going unheard on a busy Mac and Passenger quitting on macOS while VoiceOver runs. It is still free and open source under MIT, and everything it closed is in its [0.4.1 milestone](https://github.com/Zaneris/passenger/milestone/14).

## Highlights

- **Your C# formats as you type** ([#1987](https://github.com/Zaneris/passenger/issues/1987)): the `;` that ends a statement and the `}` that closes a block lay out what they end as Reformat Code would, and a block whose `}` Enter wrote for you is laid out as you leave it. One Undo takes a layout back, and Settings › Editor turns it off.
- **`passenger-ide` on every system** ([#1897](https://github.com/Zaneris/passenger/issues/1897)): open a folder, a solution or a file from a terminal on Windows and macOS as on Linux, in the Passenger already running. Windows' installer puts it on your Path, an update from 0.4.0 included; on macOS, Tools › Add the passenger-ide Command… adds it, with no administrator.
- **Your program's colours in the Run and Debug windows** ([#1814](https://github.com/Zaneris/passenger/issues/1814)): every console shows the colours and text styles a program writes, as the terminal does, so an ASP.NET app's log levels read at a glance.
- **See where a click goes, and click the links you write** ([#1901](https://github.com/Zaneris/passenger/issues/1901), [#1903](https://github.com/Zaneris/passenger/issues/1903)): hold Ctrl (Cmd on a Mac) and the name under the pointer is underlined wherever Go to Declaration can go, and a web or file address in a comment or a string opens with the same click.
- **Double-click a word to see it everywhere** ([#1950](https://github.com/Zaneris/passenger/issues/1950)): a keyword, a word in a comment or a string, or any word in Markdown or plain text lights its other places in the file and on the scrollbar.
- **Your Git branch in the status bar** ([#1918](https://github.com/Zaneris/passenger/issues/1918)): a click opens the branch list, to check out another branch or start a new one.
- **Open web apps in the browser you choose** ([#1913](https://github.com/Zaneris/passenger/issues/1913)): Settings › Run › Browser names any browser, with its arguments, for every page a run opens, Blazor WebAssembly debugging included, and a run configuration can name its own.
- **Aspire 17** ([#1893](https://github.com/Zaneris/passenger/issues/1893), [#1908](https://github.com/Zaneris/passenger/issues/1908), [#1910](https://github.com/Zaneris/passenger/issues/1910)): an AppHost as Aspire 17's templates make it, a project or a single file, runs with its Aspire window, Add Aspire Orchestration adds services as 17 does, and code help and Go to Declaration follow services added by path. Aspire 13's AppHosts work as before.

## The editor

- **Ctrl+Tab switches files** ([#1877](https://github.com/Zaneris/passenger/issues/1877)): a quick press goes back to the tab you used last; hold Ctrl to pick from your tabs in the order you used them, then the tool windows. It is Control on the Mac too, in every keymap.
- **The tab you're typing in shows it's unsaved** ([#1866](https://github.com/Zaneris/passenger/issues/1866)), with the dot every changed tab shows, where it showed its × and looked saved.
- **Scrollbar marks sit on their lines** ([#1953](https://github.com/Zaneris/passenger/issues/1953)), wrapped and folded files too, where they sat lower, by a screen's worth in a short file.
- **A global using in another file is followed** ([#1953](https://github.com/Zaneris/passenger/issues/1953)): taking one out marks the names it brought into other open files, and XAML's Create property and Create converter no longer write a using one already brings in.
- **Completion keeps the item you chose** ([#1919](https://github.com/Zaneris/passenger/issues/1919)) when a list asked again comes late, so Enter puts in your choice, not the first row.
- **Diffs say more** ([#1909](https://github.com/Zaneris/passenger/issues/1909), [#1935](https://github.com/Zaneris/passenger/issues/1935)): resting on a name in your file's side of a diff shows the editor's card, each change's » and check box say what they do, and the merge window's arrows name their keys.
- **READMEs preview as GitHub draws them** ([#1927](https://github.com/Zaneris/passenger/issues/1927)): centred rows of links, pictures at their sizes and in the look's light or dark version, and folds that open.
- **Previews keep their own ground** ([#1892](https://github.com/Zaneris/passenger/issues/1892)): a theme's picture lies behind the code alone, never over XAML Preview or the Markdown, SVG and HTML previews.
- **A library's source stays open** ([#1920](https://github.com/Zaneris/passenger/issues/1920)): on macOS and Linux, a decompiled or Source Link file Go to Declaration opened is no longer deleted when another window opens one.
- **A regex that takes too long says so** ([#1984](https://github.com/Zaneris/passenger/issues/1984)) in one wording wherever it cuts an answer short, from Find in Files and Vim's search highlight to an OpenAPI check and a Reqnroll step, where some gave a partial answer without a word.
- **Vim mode's gq and gw** ([#1751](https://github.com/Zaneris/passenger/issues/1751), [#1942](https://github.com/Zaneris/passenger/pull/1942)) indent each line again by expandtab as Vim 9.1 does, and p over v$ on an empty last line keeps the register.

## C# and XAML

- **A name the language server can't bind keeps its colour** ([#1962](https://github.com/Zaneris/passenger/issues/1962)): with its using missing or its project still loading, a type keeps a type's colour and a call a method's, where both turned a local's.
- **Rename follows the MVVM Toolkit into a MAUI page** ([#1770](https://github.com/Zaneris/passenger/issues/1770)): renaming an `[ObservableProperty]` field or a `[RelayCommand]` method renames what the toolkit makes of it in the page's C# expressions, and renaming what it makes renames the field or method.
- **XAML knows what any source generator adds** ([#1889](https://github.com/Zaneris/passenger/issues/1889)): a binding to a ReactiveUI `[Reactive]` property or `[ReactiveCommand]` command is completed and leads to its declaration, where it was marked unknown.
- **Call Hierarchy from any use** ([#1916](https://github.com/Zaneris/passenger/issues/1916)), in the window and for an agent, at a use in another file and at a record's positional property.
- **A rename asked right after a change waits for it** ([#1887](https://github.com/Zaneris/passenger/issues/1887), [#1912](https://github.com/Zaneris/passenger/issues/1912)), where it could be refused while the language server had yet to read the changed file.
- **The language server's "slow to answer" notice speaks only when you're waiting** ([#1995](https://github.com/Zaneris/passenger/issues/1995)) on a completion, a hover or Go to Declaration, or the server stops answering, never for diagnostics a busy server answers late in the background.

- **A theme brings its layout to what you haven't arranged** ([#1874](https://github.com/Zaneris/passenger/issues/1874)), leaving the windows you moved, opened or resized as they are.
- **Tool windows for one kind of project show where there is one** ([#1872](https://github.com/Zaneris/passenger/issues/1872)): Game, Aspire, Migrations, Step Library, Requests, Endpoints and the Live Visual Tree.
- **Projects brought in whole are noticed** ([#1886](https://github.com/Zaneris/passenger/issues/1886), [#1911](https://github.com/Zaneris/passenger/issues/1911)): a project, a file-based program or a Godot project copied, cloned or moved in with its folder joins your run configurations, and leaves with it.
- **Nothing cut or drawn over at any width** ([#1876](https://github.com/Zaneris/passenger/issues/1876), [#1871](https://github.com/Zaneris/passenger/issues/1871), [#1914](https://github.com/Zaneris/passenger/issues/1914), [#1922](https://github.com/Zaneris/passenger/issues/1922), [#1961](https://github.com/Zaneris/passenger/issues/1961), [#1965](https://github.com/Zaneris/passenger/issues/1965), [#1974](https://github.com/Zaneris/passenger/issues/1974)): every dialog, popup, Settings page and tool window stands on one spacing scale, and at its narrowest no words are cut mid-letter, drawn over others or pushed past the edge, from tool window headers and the status bar to the find bar and a question's answers.
- **Buttons answer the pointer** ([#1873](https://github.com/Zaneris/passenger/issues/1873)): every button lights under the pointer and deepens while pressed, so a press of Apply shows.
- **Menus open where you look for them** ([#1885](https://github.com/Zaneris/passenger/issues/1885), [#1933](https://github.com/Zaneris/passenger/issues/1933), [#1951](https://github.com/Zaneris/passenger/issues/1951), [#1959](https://github.com/Zaneris/passenger/issues/1959)): a submenu beside its item, staying open as the pointer slants into it, a right-click menu at the pointer, and a long test name shortened in its middle so Run, Debug and Until Failure stay apart.
- **A layout showing the Terminal leaves the keys with your file** ([#1906](https://github.com/Zaneris/passenger/issues/1906)), where what you typed went into the shell.
- **What's New of a patch release shows its minor release's notes beneath** ([#1881](https://github.com/Zaneris/passenger/issues/1881)), and the update notice says a security update wherever a version you skipped was one.

## Running and debugging

- **Stepping out of a handler lets the program run** ([#1891](https://github.com/Zaneris/passenger/issues/1891), [#1990](https://github.com/Zaneris/passenger/issues/1990)): leaving a web request's or a click's handler, an async one too, ends the step, where it stopped in the next request or click as if a deleted breakpoint still stood.
- **A slow getter no longer turns off a stop's other evaluations** ([#1992](https://github.com/Zaneris/passenger/issues/1992)): only an evaluation the debugger had to stop does, and it is named.
- **Evaluations at a stop no longer stall on Windows and Linux** ([#1999](https://github.com/Zaneris/passenger/issues/1999)), where one could run past its time while the runtime's background compiler was caught partway through its work.
- **Stop answers at once while a library is decompiled** ([#1967](https://github.com/Zaneris/passenger/issues/1967)), where it could wait half a minute for CoreLib's.
- **32-bit x86 programs run on Windows** ([#1888](https://github.com/Zaneris/passenger/issues/1888)) on the x86 .NET, Run naming the runtime to install where one is missing, and Debug saying before it builds that such a program debugs once built for AnyCPU.
- **Memory snapshots, live requests and metrics miss nothing as recording starts** ([#1973](https://github.com/Zaneris/passenger/issues/1973)) on .NET 11, where a collection or a request in its first moments could go unheard.
- **A compose configuration builds only what it starts** ([#1923](https://github.com/Zaneris/passenger/issues/1923)): Postgres alone builds nothing, and one service builds it and what it depends on.
- **Newer backing services** ([#1894](https://github.com/Zaneris/passenger/issues/1894)): Add › Docker Compose writes postgres:18, redis:8 and SQL Server 2025, and a compose file you already have keeps its own images and data.
- **SQL Server on Apple silicon** ([#1924](https://github.com/Zaneris/passenger/issues/1924)): Add › Docker Compose says it runs there only through the container engine's Rosetta, and where the engine has none, greys it, saying how to turn Rosetta on.

- **Titled tabs by keyboard and screen reader** ([#1870](https://github.com/Zaneris/passenger/issues/1870)): each edge of hidden windows is a region Next Region reaches, Tab moves between its tabs, Enter opens one, and every tab is named.
- **A diff's change controls have names a screen reader says** ([#1935](https://github.com/Zaneris/passenger/issues/1935)): Roll back change and Include change in commit beside each change, and the merge window's Accept and Ignore.

## Windows, macOS and Linux

- **Changes on disk are heard on a busy Mac** ([#1939](https://github.com/Zaneris/passenger/issues/1939), [#1929](https://github.com/Zaneris/passenger/issues/1929)): a commit made in a terminal, a file another program made or deleted, or a project file saved is found, where under load it could go unheard for minutes or for good.
- **Rename a loaded project's folder on Windows** ([#1940](https://github.com/Zaneris/passenger/issues/1940)): Passenger's builds, reads and language server let go of it first, and a rename another program refuses names what holds it.
- **Another program can move a folder that just came in** ([#1944](https://github.com/Zaneris/passenger/issues/1944)) on Windows, where Passenger's first look at its C# files could hold it.
- **The x64 Passenger on an Arm64 computer points you to the right one** ([#1878](https://github.com/Zaneris/passenger/issues/1878), [#1907](https://github.com/Zaneris/passenger/issues/1907)): with no x64 .NET SDK, on an Arm64 PC or under Rosetta on a Mac, it says so and links Passenger for this computer.
- **The Dock's menu follows your recent folders** ([#1976](https://github.com/Zaneris/passenger/issues/1976)) on macOS, where from its second change it showed an internal error.
- **No runtime files left behind on macOS and Linux** ([#1980](https://github.com/Zaneris/passenger/issues/1980)): a .NET program Passenger ends takes its diagnostic socket and debug pipes with it, where they piled up in the temporary folder and slowed every diagnostics tool.

## Lighter as you work

- **Faster colouring in every language** ([#1880](https://github.com/Zaneris/passenger/pull/1880)): the first file of a language opens coloured up to 56% sooner, and a file's grammar takes up to 74% less time, every colour the same.
- **A key redraws only its row** ([#1896](https://github.com/Zaneris/passenger/issues/1896)), where each letter drew the whole editor again.
- **A key on a file's first line colours only what it changed** ([#1946](https://github.com/Zaneris/passenger/issues/1946)), where on a busy machine a long line after it could be coloured again.
- **Fewer of the system's folder watchers** ([#1963](https://github.com/Zaneris/passenger/issues/1963), [#1968](https://github.com/Zaneris/passenger/issues/1968)): on macOS a window takes a handful of file-event streams, where it could take hundreds of the 1,024 the whole system allows, and on Windows it keeps about 32 MB less.
- **The debugger stays quick on a machine of few processors** ([#1971](https://github.com/Zaneris/passenger/issues/1971)): a launch reaches its stop in half a second and a request after a quiet spell is answered in milliseconds, where each waited for a free thread.
- **Expressions that make an array or name a type cost fewer calls into your program** ([#1972](https://github.com/Zaneris/passenger/issues/1972)), so they evaluate sooner on a busy machine.
- **A folder opens with less work for the C# language server** ([#1981](https://github.com/Zaneris/passenger/issues/1981)), which no longer reads its builds' files again as the window's watchers start.
