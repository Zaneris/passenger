Passenger 0.4.0 brings .NET MAUI and mobile apps into the IDE: Run, Debug and Hot Reload a .NET 11 app on an Android device or emulator, an iOS simulator or the Mac itself, under Passenger's own debugger, with MAUI's XAML previewed as you type and whatever a project still needs installed in a step. A screen reader now reads your code too: VoiceOver, Narrator, NVDA and JAWS read the editor and the terminal, and Orca on Linux reads the line the caret is on. Themes give the whole window a character, and Vim mode, Reqnroll and SpecFlow, build configurations and partial commits arrive. Opening a folder you don't know now asks before running its code. Much of this is usually found in paid IDEs or add-ons; in Passenger it is part of the IDE, still free and open source under MIT. Everything this release closed is in its [0.4.0 milestone](https://github.com/Zaneris/passenger/milestone/9).

## Highlights

- **.NET MAUI and mobile apps on a device, emulator or simulator** ([#1545](https://github.com/Zaneris/passenger/issues/1545), [#1544](https://github.com/Zaneris/passenger/issues/1544), [#1549](https://github.com/Zaneris/passenger/issues/1549), [#1746](https://github.com/Zaneris/passenger/issues/1746), [#1718](https://github.com/Zaneris/passenger/issues/1718)): pick an Android device or emulator, an iOS simulator, or the Mac itself for Mac Catalyst beside the run configuration, and Run, Debug and Hot Reload work there as on the desktop, under Passenger's own debugger, with the app's log in the Run window and its controls in the Live Visual Tree. It works for MAUI, Avalonia and .NET for Android apps, and a MAUI app opened on Windows runs its Windows head from the same chooser.
- **MAUI's XAML, with a live preview** ([#1547](https://github.com/Zaneris/passenger/issues/1547), [#1590](https://github.com/Zaneris/passenger/issues/1590), [#1548](https://github.com/Zaneris/passenger/issues/1548)): completion, Go to Declaration, Find Usages and live checks, compiled bindings and .NET 11's C# expressions included, and a MAUI 11 page previews beside its XAML on Windows, macOS and Linux as a phone, tablet or desktop, light or dark. - **Screen readers read Passenger** ([#1845](https://github.com/Zaneris/passenger/issues/1845), [#1846](https://github.com/Zaneris/passenger/issues/1846)): the editor and the terminal read as a text field does, completion, Parameter Info, status messages and trees are heard too, and a pair of keys moves between the window's regions. - **Themes with character** ([#1342](https://github.com/Zaneris/passenger/issues/1342), [#1852](https://github.com/Zaneris/passenger/issues/1852), [#1576](https://github.com/Zaneris/passenger/issues/1576)): a theme now sets the layout, fonts, shapes and a faint picture behind your code as well as its colours, as every theme in Passenger's themes repository now does, from Harbour's tide lines to Moss's ferns. Browse VS Code Themes brings in any colour theme on Open VSX.

## Security

0.3.4 and earlier are affected by five advisories that this release fixes.

- **A folder's code runs only once you trust it** ([GHSA-xjmh-rgxw-cm3x](https://github.com/Zaneris/passenger/security/advisories/GHSA-xjmh-rgxw-cm3x), [GHSA-7v8w-74wp-p6h8](https://github.com/Zaneris/passenger/security/advisories/GHSA-7v8w-74wp-p6h8), [#1823](https://github.com/Zaneris/passenger/issues/1823)): Passenger asks the first time you open a folder, and until you trust it you read and edit its files while none of its code runs: no build, restore, analyzer or test, and none of the programs its Git configuration names. Trust Folder starts it all without a restart, and Settings › Trusted Folders lists your answers.
- **An agent stays in your open folder and asks before each change** ([GHSA-f388-mrvw-xp5v](https://github.com/Zaneris/passenger/security/advisories/GHSA-f388-mrvw-xp5v), [#1841](https://github.com/Zaneris/passenger/issues/1841)): Allow Once or Allow for This Session, the question showing each argument whole.
- **Smaller fixes** ([GHSA-5mh4-xw42-9p6q](https://github.com/Zaneris/passenger/security/advisories/GHSA-5mh4-xw42-9p6q), [GHSA-57mq-vwcv-q6cq](https://github.com/Zaneris/passenger/security/advisories/GHSA-57mq-vwcv-q6cq), [#1834](https://github.com/Zaneris/passenger/issues/1834), [#1832](https://github.com/Zaneris/passenger/issues/1832)): a crafted `.editorconfig` or route pattern can't freeze the window, a path in a program's output never reaches another machine, a file another user put in a folder above yours is passed over, agents' answers mask secrets, your state folder and Local History are yours alone, and JSON and YAML schemas are read only from this machine's disks (YAML's server now needs Node.js 22.15 or later).
- **A security release says so** ([#1822](https://github.com/Zaneris/passenger/issues/1822)): from now on the update notice names one, says what it fixes and offers to restart into it.

- **Solution-wide analysis does less** ([#1559](https://github.com/Zaneris/passenger/issues/1559), [#1475](https://github.com/Zaneris/passenger/issues/1475)): installing a workload or SDK costs it nothing, and it drops work on a solution that has moved on, from 115 s of CPU to 71 on a 32-project solution.
- **A refactoring that moves 1,200 files tells Git in one go** ([#1604](https://github.com/Zaneris/passenger/issues/1604)), where it ran git 2,400 times.
- **A key in a long soft-wrapped file redraws less** ([#1439](https://github.com/Zaneris/passenger/issues/1439)).
