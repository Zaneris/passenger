Passenger 0.4.5 keeps your packages to the versions you chose and your stashes where you left them. The NuGet window offers only the updates a reference's version range allows, so a `[14.0.0]` pin stays put and `10.*` stays on 10, and its Updates tab can list your own references apart from the packages they bring in. A double-click on a stash now shows what it holds instead of popping it. Quick Fix adds EF Core's `using` for `FirstOrDefaultAsync` and the rest of its async queries, the cards over your code can be selected and copied, a library's launch profiles run, XAML Preview reaches more WPF projects, Next Tab and Previous Tab switch the Terminal's shells, and on Windows git is found where you installed it for yourself alone, as Scoop does. It is still free and open source under MIT, and everything it closed is in its [0.4.5 milestone](https://github.com/Zaneris/passenger/milestone/20).

## Highlights

- **NuGet keeps to your version ranges** ([#2240](https://github.com/Zaneris/passenger/issues/2240)): a pinned `[14.0.0]` is offered nothing newer and `10.*` only 10.x, and a newer version a range keeps out is tagged "held back", saying why. An update keeps a pin a pin and a floating version as you wrote it.
- **Updates of your own references alone** ([#2243](https://github.com/Zaneris/passenger/issues/2243)): the Updates tab's Sort and Filter lists your projects' own references, or only the packages they bring in, and Update All takes only what the filter shows. A fix for a vulnerable version always shows.
- **A stash opens on a double-click, never pops** ([#2239](https://github.com/Zaneris/passenger/issues/2239)): Enter or a double-click in Unstash Changes lists the stash's files in the Git window, each beside your working tree's. Nothing is applied, and only Pop puts it back.
- **EF Core's `using` from Quick Fix** ([#2266](https://github.com/Zaneris/passenger/issues/2266)): `FirstOrDefaultAsync`, `ToListAsync`, `CountAsync`, `AnyAsync` and EF Core's other async queries on an `IQueryable` are offered `using Microsoft.EntityFrameworkCore;`, as any missing name is, where .NET 10's own `AsyncEnumerable` hid the fix.
- **Copy from the cards over your code** ([#2259](https://github.com/Zaneris/passenger/issues/2259)): an error's card, a symbol's, Parameter Info and a completion item's documentation stay as the pointer moves onto them, and their words can be selected and copied.
- **A library's launch profiles run** ([#2223](https://github.com/Zaneris/passenger/issues/2223)): a library project's profile that starts a program, such as a host that loads it, is a run configuration you can run and debug like any other.
- **XAML Preview for more WPF projects** ([#2251](https://github.com/Zaneris/passenger/issues/2251)): a project on a drive another Windows account owns previews where it was greyed, and a WPF app built for x86 previews on 32-bit .NET.
- **Git found on Windows wherever you installed it** ([#2265](https://github.com/Zaneris/passenger/issues/2265)): git, and every program Passenger runs by name, is found on your own Path even when Passenger was started without it on its PATH, as happens just after a Scoop install.

## NuGet

- **The newest version your range allows** ([#2240](https://github.com/Zaneris/passenger/issues/2240)): each project moves to the newest version all its references take, a package's details choose that version for you, and an update outside the range says so on hover. An interval moves on from the version you take (`[1.1.0, 2.0.0)`), and a floating version restores to its newest.
- **Update All, as filtered** ([#2240](https://github.com/Zaneris/passenger/issues/2240), [#2243](https://github.com/Zaneris/passenger/issues/2243)): it updates what the filters and the project chosen in Used By leave, skips a reference a version falls outside of, and says when nothing is left. A vulnerability fix for a package you get through another is tagged as one, saying what brings it in.

## The editor and the Terminal

- **Cards you can work in** ([#2259](https://github.com/Zaneris/passenger/issues/2259)): a card stays while the pointer, the keys or its menu are on it. Cmd+C (Ctrl+C) or the right-click Copy copies what you selected, and Escape closes it and gives the editor its keys back. Copy and Select All in a Markdown preview or a value in Details now act on that text too.
- **Tabs where the keys are** ([#2262](https://github.com/Zaneris/passenger/issues/2262)): Next Tab and Previous Tab, with your keymap's keys (`Cmd+Shift+]` and `Cmd+Shift+[` on a Mac), switch the Terminal's shells while it has the keys, a tool window's tabs (Problems, Find, Git, NuGet and the rest) while it does, and the editor's tabs everywhere else.

## Git and diffs

- **See a stash before you pop it** ([#2239](https://github.com/Zaneris/passenger/issues/2239)): its tab, "Compare stash@{0} and Working Tree", lists the files it changed, the ones it renamed and the untracked files it put away, each opening as the stash has it beside your own.
- **A new file reads as new** ([#2258](https://github.com/Zaneris/passenger/issues/2258)): its diff says "New file" on the side that had none and marks every line as added, in the diff window and in a diff tab alike. A deleted file's diff says "Deleted file" the same way.

## Running and previews

- **Libraries with launch profiles** ([#2223](https://github.com/Zaneris/passenger/issues/2223)): Run and Debug build the library and start the program its profile names (`commandName: Executable`), with its arguments and folder, and the profile shows its run mark in `launchSettings.json` and in Edit Configurations.
- **XAML Preview, found and loaded** ([#2251](https://github.com/Zaneris/passenger/issues/2251)): on a drive kept from an earlier Windows install or from another PC, a XAML file gets its project's preview, completion and checks, and an x86 WPF app's preview names the .NET runtime to install for x86 where it's missing.

## Fixed

### C# completion

- **A `(` typed after a method completion steps over its brackets** ([#2235](https://github.com/Zaneris/passenger/issues/2235)), as `)` does, where typing them by habit doubled them into `(())`; GDScript's calls too.
- **An extension method from a namespace not yet imported is listed as you type its name** ([#2237](https://github.com/Zaneris/passenger/issues/2237)), a package's on a chained builder among them, even before C# has finished indexing your references.

### Aspire

- **The dashboard's console logs have no stray empty lines** ([#2254](https://github.com/Zaneris/passenger/issues/2254)): a service Passenger starts for an AppHost sends its output a line at a time, as `aspire run` does, so no empty line follows each write and no line shows broken in two.

### The window

- **The Containers and Requests windows have icons of their own** ([#2264](https://github.com/Zaneris/passenger/issues/2264)), no longer NuGet's and Endpoints', and the checked-out branch's mark in the Git window's branches stands out in every theme, its row chosen too, where in some themes it was the faintest in the list.

### Vim mode

- **More visual `is` and `as` as Vim leaves them** ([#2224](https://github.com/Zaneris/passenger/issues/2224)): from an empty line between paragraphs or ending the text, from the white after a sentence, carried back over a line's end, and over white at the text's end, they take the stretch Vim 9.2 takes, held to Vim's own answers over tens of thousands of cases.
- **A block's `A` after `.`** ([#2256](https://github.com/Zaneris/passenger/issues/2256)): once `.` repeats a characterwise or linewise visual operator, a visual block's `A` appends at the column Vim's does.
