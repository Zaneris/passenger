Passenger 0.4.4 is on Homebrew: `brew install passenger-ide` installs it on a Mac, with its `passenger-ide` command on your PATH. A C# Godot game stopped at a breakpoint in the Game window no longer freezes Passenger on Windows, and a test run now builds only what its tests need, however many solutions share your folder. Typing `///` writes a member's doc comment, Passenger's refactorings are in Refactor This and the right-click menu, Alt+Enter pulls a member up into its interface, Ctrl+Alt shortcuts work on keyboard layouts with AltGr, Run on an iOS simulator opens the simulator's window, file-based programs build and run on .NET 10's first SDKs, and Vim mode does what Vim does in many more cases. It is still free and open source under MIT, and everything it closed is in its [0.4.4 milestone](https://github.com/Zaneris/passenger/milestone/19).

## Highlights

- **On Homebrew** ([Homebrew/homebrew-cask#305302](https://github.com/Homebrew/homebrew-cask/pull/305302)): `brew install passenger-ide` installs Passenger on any Mac, Apple Silicon or Intel, and puts the `passenger-ide` command on your PATH. It updates itself in place, as the disk image's copy does.
- **Godot games stop cleanly on Windows** ([#2215](https://github.com/Zaneris/passenger/issues/2215)): a C# game drawn in the Game window that stops at a breakpoint no longer freezes Passenger. The pane keeps the game's last picture and says it is stopped in the debugger, and the game comes back on Continue.
- **A test run builds only what it tests** ([#2208](https://github.com/Zaneris/passenger/issues/2208)): running one test builds its test project and the projects it references, never every project of a folder with several solutions.
- **`///` writes the doc comment** ([#2206](https://github.com/Zaneris/passenger/issues/2206)): a summary, a `<param>` for each parameter and its `<returns>`, with the caret in the summary, and Enter inside a doc comment carries on with `///`.
- **Refactorings where you look for them** ([#2204](https://github.com/Zaneris/passenger/issues/2204)): Refactor This and the editor's right-click Refactor menu list Passenger's own refactorings, Pull Members Up among them, and Alt+Enter on a member's name pulls it up into an interface the class implements.
- **Ctrl+Alt shortcuts with AltGr layouts** ([#2209](https://github.com/Zaneris/passenger/issues/2209)): on Windows, Ctrl+Alt+L on a Polish keyboard runs its shortcut, Reformat Code in the IntelliJ IDEA keymap, while AltGr+L still types ł, and so on every layout where AltGr types a character.
- **The simulator's window on Run** ([#2218](https://github.com/Zaneris/passenger/issues/2218)): Run and Debug on an iOS simulator open its window, in the background so your keys stay where they were.
- **.NET 10's first SDKs** ([#2181](https://github.com/Zaneris/passenger/issues/2181)): a file-based program beside your solution loads, builds and runs on every .NET 10 SDK, where the earliest refused it.

## Refactoring and C#

- **Refactor This lists Passenger's refactorings first** ([#2204](https://github.com/Zaneris/passenger/issues/2204)), in the Refactor menu's order and each with its keys: only those that can run at the caret, and none of the language server's actions listed twice.
- **The right-click Refactor menu is the main menu's** ([#2204](https://github.com/Zaneris/passenger/issues/2204)): every refactoring the main menu has, where it held five.
- **Pull into an interface from Alt+Enter** ([#2204](https://github.com/Zaneris/passenger/issues/2204)): on the name of a class's public member, Show Context Actions offers each interface the class implements that lacks it, declaring the member there with no dialog, in one step of Undo.
- **Doc comments as you type** ([#2206](https://github.com/Zaneris/passenger/issues/2206)): the template `///` writes is the language server's own, one Undo takes it back with the slash, and it comes whatever Settings' Format on Type says.

## Running and testing

- **Several test projects, one build** ([#2208](https://github.com/Zaneris/passenger/issues/2208)): a run from the caret, the gutter, the Unit Tests window or an agent's `tests_run` builds the test projects it needs side by side, so a project two of them reference builds once; Run All Tests leaves the projects no test references unbuilt.
- **The Game window while the debugger holds the game** ([#2215](https://github.com/Zaneris/passenger/issues/2215)): Passenger stays responsive through every stop, step and Continue, and the game's window comes back over the pane as soon as the game answers again.
- **Simulator or Device Hub** ([#2218](https://github.com/Zaneris/passenger/issues/2218)): the simulator's window opens through the Simulator app, or through Device Hub with Xcode 27, which has no Simulator app; a window that doesn't open is said in the Run console and the run goes on.
- **File-based programs on .NET 10's first SDKs** ([#2181](https://github.com/Zaneris/passenger/issues/2181)): a program beside your solution builds, runs and has the language server's help on every .NET 10 SDK, where the SDKs before 10.0.400 failed its build with MSB4025 and the first ones made no project of it.

## Fixed

### The debugger

- **An async program's unhandled exception stops at its throw** ([#2177](https://github.com/Zaneris/passenger/issues/2177)), with its locals, on a busy machine too, where it could stop at the rethrow in the method awaiting it.

### Refactoring

- **C#'s refactorings grey in other languages** ([#2220](https://github.com/Zaneris/passenger/issues/2220)): Change Signature, Extract Interface, Move, Safe Delete, Pull Members Up and Push Members Down grey in a TypeScript or other web file, saying the file is not C#, where they stayed enabled and failed when run. In GDScript, Change Signature, Move and Safe Delete still do their own.

### Keys

- **AltGr and Ctrl+Alt told apart on Windows** ([#2209](https://github.com/Zaneris/passenger/issues/2209)) by the keys you hold, in the editor and the Terminal alike: Ctrl+Alt held with its own keys runs the shortcut, or reaches the shell as Ctrl and Alt, and AltGr types its character.

### Vim mode

- **Visual `is` and `as` as Vim leaves them** ([#2115](https://github.com/Zaneris/passenger/issues/2115), [#2182](https://github.com/Zaneris/passenger/issues/2182), [#2210](https://github.com/Zaneris/passenger/issues/2210), [#2216](https://github.com/Zaneris/passenger/issues/2216), [#2217](https://github.com/Zaneris/passenger/issues/2217), [#2219](https://github.com/Zaneris/passenger/issues/2219)): from every visual mode, with or without a count, over sentences, white and empty lines, they take the stretch and leave the mode Vim 9.2 does, held to Vim's own answers over thousands of random key sequences.
- **Counted inserts, `.` and blocks** ([#2182](https://github.com/Zaneris/passenger/issues/2182), [#2210](https://github.com/Zaneris/passenger/issues/2210), [#2216](https://github.com/Zaneris/passenger/issues/2216), [#2217](https://github.com/Zaneris/passenger/issues/2217), [#2219](https://github.com/Zaneris/passenger/issues/2219)): `3A` and `2o` make each line break they type again as Enter does, with its indent; `{count}|` in visual mode stands past a short line's end; a visual `A` made after `$`, and `.` after it, type where Vim's do; block `J` and `gJ`, `:>` and `:<` over empty lines and a `gp` of an empty register leave `j`, `k` and `yy` aiming where Vim's do; and `yas`, `das` and `cas` over blank lines take the lines Vim takes.
