Passenger 0.3.0 is an IDE for Godot 4 games, in C# and in GDScript: Run, Debug, Profile and Hot Reload of the game, its C# checked against its scenes, GDScript and shaders read as Godot reads them with no Godot running for it, the running game's tree and values beside its code, its tests in the Unit Tests window, and Passenger's own addon for Godot's editor. Blazor's WebAssembly components now debug in the browser, Aspire's window charts each resource's metrics, Publish ships container images and AppHosts, Avalonia and WPF apps take XAML Hot Reload, IntelliJ IDEA's keymap joins Visual Studio's and VS Code's, and a large file scrolls without dropping a frame. Most of this usually takes a paid IDE or a paid add-on; in Passenger it is part of the IDE, free and open source under MIT, with no account, no licence key and no telemetry. Everything it closed is in its [0.3.0 milestone](https://github.com/Zaneris/passenger/milestone/6).

## Added

### Godot 4: running, debugging and Hot Reload

- **A Godot 4 project runs from Passenger** ([#1065](https://github.com/Zaneris/passenger/issues/1065), [#1087](https://github.com/Zaneris/passenger/issues/1087)): a game in C# gets two run configurations, the game and Godot's editor on it, and Run, Debug, Profile and Hot Reload reach the game. Settings › Godot names the Godot found (GODOT, the PATH, your applications) with its version, and a project whose Godot.NET.Sdk is newer than that Godot is refused saying why.
- **Run with Hot Reload applies edits to a running game** ([#1086](https://github.com/Zaneris/passenger/issues/1086)), as Debug does, with no debug session shown.
- **A game of GDScript alone runs, debugs, profiles and Hot Reloads** ([#1105](https://github.com/Zaneris/passenger/issues/1105), [#1125](https://github.com/Zaneris/passenger/issues/1125)): a folder with a project.godot and no C# project, on any Godot 4 build, .NET or not, with its external console and Attach Profiler; a member is set from Variables.
- **GDScript debugs beside the game's C#** ([#1069](https://github.com/Zaneris/passenger/issues/1069)): Debug opens a GDScript tab beside the game's own, breakpoints stop in either language, and a saved script reloads in the running game ([#1188](https://github.com/Zaneris/passenger/issues/1188): Apply Hot Reload Changes saves the scripts first).
- **Run Current Scene** starts the game in the scene open in the editor.
- **Several copies of a game run side by side, for multiplayer** ([#1117](https://github.com/Zaneris/passenger/issues/1117)): up to 16, each with its own arguments, debugged as one group that one Stop ends.
- **A game can draw inside Passenger**, in its Game window beside the code, the tree and the console, on Windows, on macOS (Godot 4.5 and newer, through Godot's embedded display) and on Linux under X11 ([#1127](https://github.com/Zaneris/passenger/issues/1127)): the game takes the keys when clicked, and Ctrl+F11 gives them and takes them back.
- **Godot's types read as a game developer reads them** in Variables, watches and the hover ([#1110](https://github.com/Zaneris/passenger/issues/1110)): Vector2, Vector3, Rect2, Aabb, Quaternion, Transform2D, Color and the rest.
- **Mute Game Audio** on the Debug window's toolbar silences a debugged game ([#1119](https://github.com/Zaneris/passenger/issues/1119)).
- **New Solution and New Project make a Godot 4 game**, in C# or GDScript, ready to run ([#1113](https://github.com/Zaneris/passenger/issues/1113), [#1140](https://github.com/Zaneris/passenger/issues/1140)), its solution beside project.godot as Godot's editor lays one out.
- **Publish exports a game through its export presets** ([#1112](https://github.com/Zaneris/passenger/issues/1112)), templates installed from a `.tpz` you choose.
- **A Godot project has a page of its own** ([#1132](https://github.com/Zaneris/passenger/issues/1132)): its version, main scene, autoloads, input map, export presets and plugins, each change asked first and one Undo.
- **Passenger is Godot's script editor in one step** ([#1095](https://github.com/Zaneris/passenger/issues/1095)): Tools › Make Passenger Godot's Script Editor… sets Godot's editor to open a script in the Passenger window already open, at its line, and Open in Godot Editor opens Godot's editor on the scene and node at hand ([#1133](https://github.com/Zaneris/passenger/issues/1133)).
- **Godot's launch profiles run as Passenger's own configuration does** ([#1176](https://github.com/Zaneris/passenger/issues/1176)), Chickensoft's `%GODOT%` profiles among them.
- **C# script templates that fit the project** for Godot's Attach Script dialog ([#1194](https://github.com/Zaneris/passenger/issues/1194)), kept out of the game's build.
- **F1 on a Godot class or member opens its page in Godot's documentation** ([#1118](https://github.com/Zaneris/passenger/issues/1118)), for the version found.
- **A game's Ogg and MP3 sounds play from their preview** on every system ([#1155](https://github.com/Zaneris/passenger/issues/1155)).

### Godot 4: C# checked against its scenes

- **A game's C# is read against its scenes** ([#1067](https://github.com/Zaneris/passenger/issues/1067)): `GetNode<T>` paths and types, `res://` paths, `[Export]` values and the scenes' node paths are completed, checked and led to, and a rename reaches the scenes.
- **Signals and their handlers lead to each other and are checked** ([#1068](https://github.com/Zaneris/passenger/issues/1068), [#1100](https://github.com/Zaneris/passenger/issues/1100)): a connection to a method the script lacks, or one taking the wrong arguments, is marked, and a signal's rename leaves no use of its event or SignalName broken.
- **Connections and calls by string are checked and lead to what they name** ([#1101](https://github.com/Zaneris/passenger/issues/1101)): `EmitSignal("x")`, `Connect`, `Call`, `uid://` paths, exported nodes, and the paths a move or rename in the Explorer changes, written anew in every scene and resource.
- **Every string Godot takes is completed, checked and renamed** ([#1108](https://github.com/Zaneris/passenger/issues/1108), [#1136](https://github.com/Zaneris/passenger/issues/1136)): input actions, groups, animations (AnimationTree's and SpriteFrames' too), autoloads, shader parameters, translations, named layers and global shader uniforms; theme items too, by type variation and the scene's node type ([#1192](https://github.com/Zaneris/passenger/issues/1192), [#1215](https://github.com/Zaneris/passenger/issues/1215)).
- **An open scene is marked where Godot would not load what it says** ([#1104](https://github.com/Zaneris/passenger/issues/1104)), as it opens and as its C# changes, and the marks offer their fixes ([#1131](https://github.com/Zaneris/passenger/issues/1131)), each one Undo.
- **Scenes show beside the code** ([#1130](https://github.com/Zaneris/passenger/issues/1130)): a mark on a script's class lists the scenes it runs in, node paths carry their node's class, and a `res://` path shows its file.
- **A scene's tree is its outline** in Structure and File Structure ([#1114](https://github.com/Zaneris/passenger/issues/1114)), and a node chosen there shows and edits its properties as Godot's inspector does, with the live tree's value editors ([#1202](https://github.com/Zaneris/passenger/issues/1202), [#1240](https://github.com/Zaneris/passenger/issues/1240)).
- **C# and GDScript lead to each other** ([#1115](https://github.com/Zaneris/passenger/issues/1115), [#1166](https://github.com/Zaneris/passenger/issues/1166), [#1169](https://github.com/Zaneris/passenger/issues/1169), [#1237](https://github.com/Zaneris/passenger/issues/1237)): calls, connections and usages across the two, a GDScript member completed and renamed from a C# string, and a node's C# script's members from GDScript.
- **A scene edited in Godot and in Passenger keeps both** ([#1190](https://github.com/Zaneris/passenger/issues/1190), [#1224](https://github.com/Zaneris/passenger/issues/1224)): Passenger never writes over what your Godot editor holds unsaved, and asks first.
- **Large Godot projects stay fast** ([#1199](https://github.com/Zaneris/passenger/issues/1199)): a key in a scene or script costs what it changed, not the project's size.

### Godot 4: GDScript and shaders, read as Godot reads them

- **GDScript is Passenger's own** ([#1196](https://github.com/Zaneris/passenger/issues/1196), [#1228](https://github.com/Zaneris/passenger/issues/1228), [#1245](https://github.com/Zaneris/passenger/issues/1245)): a tokenizer, parser and analyzer ported from Godot's own, which type every member as Godot does, give Godot's warnings and errors in its words on its lines, and answer completion, the hover, Parameter Info, Find Usages, Rename and the outline, with no Godot running for them. Godot's own language server is asked only for what Passenger's reading can't answer, and let go after three minutes with no GDScript open.
- **GDScript is coloured as C# is**, each name by what Passenger's reading says it is, and its fixes come with its marks.
- **Reformat Code lays GDScript out as Godot's style guide does** ([#1197](https://github.com/Zaneris/passenger/issues/1197), [#1230](https://github.com/Zaneris/passenger/issues/1230)), wrapping long lines inside their brackets and keeping gdlint's ignores, and Order Script's Parts puts them in the guide's order.
- **GDScript's refactorings reach every caller** ([#1198](https://github.com/Zaneris/passenger/issues/1198)): Rename, Change Signature, Move to another script and a signal's signature, through connections in scenes and C# strings alike; an override renames with its whole family, and a rename where Passenger can't see every use names each place and is made only if you choose.
- **Shaders are checked by Passenger's own port of Godot's shader compiler** ([#1182](https://github.com/Zaneris/passenger/issues/1182), [#1256](https://github.com/Zaneris/passenger/issues/1256)): every error and warning at once, in Godot's words at their lines, under the project's rendering method and warning settings, a `.gdshader`, a `.gdshaderinc` and a scene's own Shader alike, with no Godot running for them.
- **Shaders complete and hover as Godot's language has them** ([#1182](https://github.com/Zaneris/passenger/issues/1182), [#1205](https://github.com/Zaneris/passenger/issues/1205)): the built-ins of the function the caret is in, render and stencil modes, hints, the include's functions and Context Help, as the Godot found takes them.

### Godot 4: the running game

- **The running game's scene tree, values, errors and monitors** come into the Live Visual Tree over Godot's own remote debug protocol ([#1066](https://github.com/Zaneris/passenger/issues/1066), [#1090](https://github.com/Zaneris/passenger/issues/1090)), following the game as it changes, for every game running.
- **A game's values are tuned with editors fit for them** ([#1126](https://github.com/Zaneris/passenger/issues/1126), [#1102](https://github.com/Zaneris/passenger/issues/1102)): a colour's swatch, a range's slider, a vector's parts, arrays, dictionaries and resources, and Keep writes a value back into its scene with one click.
- **Select a node by clicking in the game**, and pause the game's loop or step it a frame ([#1111](https://github.com/Zaneris/passenger/issues/1111)), in 2D and 3D, on Godot 4.7 and 4.8 ([#1231](https://github.com/Zaneris/passenger/issues/1231)).
- **A running game's member values show in the code**, at each line's end, with no breakpoint ([#1129](https://github.com/Zaneris/passenger/issues/1129)).
- **A game's runtime errors stay pinned to their lines** after the run, counted, and Godot's console folds its repeats ([#1128](https://github.com/Zaneris/passenger/issues/1128)).
- **Frame time and a game's own custom monitors are charted live** while it runs ([#1116](https://github.com/Zaneris/passenger/issues/1116)).

### Godot 4: profiling, tests and Godot's editor

- **A game's profile holds both languages in one call tree** ([#1096](https://github.com/Zaneris/passenger/issues/1096), [#1201](https://github.com/Zaneris/passenger/issues/1201)): GDScript's functions and Godot's frame times beside the C# samples, a slow frame opening on what it spent, and memory snapshots of the game.
- **GdUnit4, GUT and GoDotTest tests run and debug in the Unit Tests window** ([#1109](https://github.com/Zaneris/passenger/issues/1109), [#1146](https://github.com/Zaneris/passenger/issues/1146), [#1177](https://github.com/Zaneris/passenger/issues/1177), [#1209](https://github.com/Zaneris/passenger/issues/1209)), found from the code before any build, each outcome as its test ends, the project and your Godot left as they were.
- **Passenger's own addon for Godot's editor** ([#1189](https://github.com/Zaneris/passenger/issues/1189), [#1216](https://github.com/Zaneris/passenger/issues/1216)): a game Godot's Play starts is built, debugged and seen in Passenger like one it launches, every instance of it; Passenger plays and stops the game in your Godot editor and has it reload its scripts after a build ([#1193](https://github.com/Zaneris/passenger/issues/1193)), and completion takes what the open editor knows through its IDE protocol ([#1192](https://github.com/Zaneris/passenger/issues/1192)).

### Godot 4: your coding agent

- **Agents run, see, drive and debug a Godot game through MCP** ([#1070](https://github.com/Zaneris/passenger/issues/1070), [#1159](https://github.com/Zaneris/passenger/issues/1159), [#1181](https://github.com/Zaneris/passenger/issues/1181)), as they do an Avalonia app: its tree, its members' values, clicks and keys, a breakpoint's stop, every copy running.
- **Agents act in your Godot editor** through Passenger's addon with one new tool, `godot_editor` ([#1191](https://github.com/Zaneris/passenger/issues/1191), [#1229](https://github.com/Zaneris/passenger/issues/1229), [#1232](https://github.com/Zaneris/passenger/issues/1232)): open, read and change a scene as the editor holds it, each change one step of Godot's Undo, its NodePaths kept true.
- **An agent's own Passenger sees its games' frames** with no window on your screen ([#1203](https://github.com/Zaneris/passenger/issues/1203)): on macOS through Godot's embedded display, on Windows on a desktop of its own, and on Linux on Passenger's own Xvfb where one is installed, and a Passenger nobody sees never shows a game's window there ([#1158](https://github.com/Zaneris/passenger/issues/1158)).
- **An agent's code actions in a GDScript are the window's own** ([#1239](https://github.com/Zaneris/passenger/issues/1239)), and its diagnostics name each warning by its code ([#1213](https://github.com/Zaneris/passenger/issues/1213)).

### Aspire, containers, telemetry and publish

- **The Aspire window shows each resource's references and waits both ways** ([#587](https://github.com/Zaneris/passenger/issues/587)), **charts its metrics** on a Stats tab while someone looks ([#1081](https://github.com/Zaneris/passenger/issues/1081)), and draws the AppHost as a graph ([#1235](https://github.com/Zaneris/passenger/issues/1235)).

- **An app's OpenAPI document becomes requests** in the Endpoints window ([#425](https://github.com/Zaneris/passenger/issues/425), [#1225](https://github.com/Zaneris/passenger/issues/1225)), its responses checked against the document, read from the running app or the build alone.

### Avalonia and WPF

### Debugging

- **Step Out of an async method lists the value it returned** in Variables ([#227](https://github.com/Zaneris/passenger/issues/227)).
- **An evaluation stuck on a thread it holds runs again with every thread let go** ([#601](https://github.com/Zaneris/passenger/issues/601), [#1089](https://github.com/Zaneris/passenger/issues/1089)), and Threads and Call Stack then show where the threads moved.
- **A breakpoint says its state** in the gutter's hover and in Problems, why it didn't bind among it, and one on a line no code runs on where it moves to ([#1093](https://github.com/Zaneris/passenger/issues/1093)).
- **A stop on an exception always names it** ([#1107](https://github.com/Zaneris/passenger/issues/1107)), and its stack trace is read from the frames it stores, running no code in the program ([#1123](https://github.com/Zaneris/passenger/issues/1123)).
- **A dictionary's rows name their values' types**, and an assembly's `[DebuggerDisplay]` for another type is honoured ([#1139](https://github.com/Zaneris/passenger/issues/1139)).
- **Hot Reload calls a program's update handlers** under Attach, in Aspire's debug sessions and in debugged test hosts too ([#1099](https://github.com/Zaneris/passenger/issues/1099), [#1122](https://github.com/Zaneris/passenger/issues/1122)).
- **A memory snapshot of a program macOS keeps from others** (signed with the hardened runtime, as a notarized app is) is made from the runtime's own GC heap dump ([#1103](https://github.com/Zaneris/passenger/issues/1103)).

### Git

- **Commit signing with SSH, GPG or X.509**, set up and asked for in Passenger ([#241](https://github.com/Zaneris/passenger/issues/241), [#1175](https://github.com/Zaneris/passenger/issues/1175)): the Commit window says which key signs, a key's passphrase is asked in Passenger's own dialog (Git for Windows' gpg too), and merges, rebases and cherry-picks sign as commits do.

### .NET, tests and Linux

- **Without a .NET SDK, Passenger says what is missing and installs one in a step** ([#1120](https://github.com/Zaneris/passenger/issues/1120), [#1137](https://github.com/Zaneris/passenger/issues/1137)), asked first: no .NET at all, a runtime alone, the SDK global.json asks for, or a project targeting a newer .NET than the folder's SDK builds, and what still works meanwhile.

- **A Linux install updates itself** as macOS and Windows do ([#600](https://github.com/Zaneris/passenger/issues/600), [#1219](https://github.com/Zaneris/passenger/issues/1219)), on every major distribution, for one person or for everyone.

## Changed

- **Passenger's command on Linux is `passenger-ide`** ([#1083](https://github.com/Zaneris/passenger/issues/1083)), after the site's domain, so it never meets Phusion Passenger's `passenger`; an install's own `passenger` link moves to the new name, and `install.sh` names the package to install where your distribution has no font.
- **A `.gdshaderinc` is checked on its own**, as Godot's shader editor checks one, where it was compiled as the first shader including it; a shader's errors in an include still show on its `#include`.
- **The window's words are drawn in Inter 4.1's hinted faces**, carried by Passenger ([#1217](https://github.com/Zaneris/passenger/issues/1217)), sharp at 100% on Windows and Linux, and San Francisco on macOS is set as the system's own apps set it ([#1222](https://github.com/Zaneris/passenger/issues/1222)).

### Faster and leaner

- **A large C# file scrolls without dropping a frame** ([#1151](https://github.com/Zaneris/passenger/issues/1151), [#1157](https://github.com/Zaneris/passenger/issues/1157), [#1161](https://github.com/Zaneris/passenger/issues/1161), [#1164](https://github.com/Zaneris/passenger/issues/1164)): each row is drawn once and moved as the view scrolls, a key redraws only the rows it changed, and a frame through a 50,000-line file with thousands of warnings takes 2.1 ms at the median, as a small file's does, where it took 11.
- **Passenger and what it starts hold less memory** ([#1153](https://github.com/Zaneris/passenger/issues/1153), [#1246](https://github.com/Zaneris/passenger/issues/1246)): on Passenger's own solution, Roslyn's server about 2.0 GB where it held 2.4 to 2.5, the project host 231 MB where it held 345 to 478, and Godot's headless editor for GDScript let go after three minutes unused.
- **Opening a folder reads its tests from the last opening's cache** ([#1253](https://github.com/Zaneris/passenger/issues/1253)), parsing only the files changed since: a second opening of Passenger's own solution lists its 3,415 tests in under a quarter of a second, where every opening spent 2 to 4 s parsing them beside the language server's own start.
- **An agent's second diagnostics of an unchanged file answer in about 0.1 s** from the server's last pull ([#1238](https://github.com/Zaneris/passenger/issues/1238)).
- **The rest of the sweep** ([#1152](https://github.com/Zaneris/passenger/issues/1152)): the Explorer's filter, a file of thousands of problems, a diff of thousands of lines (now shown change by change, [#1251](https://github.com/Zaneris/passenger/issues/1251)), a large C# file's first parse, a console's flood, a build's churn under the folder watcher, the Unit Tests model, web routes' bodies, a memory snapshot, a game erring every frame and the first Find Usages in a project with XAML each cost what they need and no more ([#1241](https://github.com/Zaneris/passenger/issues/1241), [#1242](https://github.com/Zaneris/passenger/issues/1242), [#1243](https://github.com/Zaneris/passenger/issues/1243), [#1244](https://github.com/Zaneris/passenger/issues/1244), [#1247](https://github.com/Zaneris/passenger/issues/1247), [#1248](https://github.com/Zaneris/passenger/issues/1248), [#1249](https://github.com/Zaneris/passenger/issues/1249), [#1250](https://github.com/Zaneris/passenger/issues/1250), [#1252](https://github.com/Zaneris/passenger/issues/1252), [#1254](https://github.com/Zaneris/passenger/issues/1254), [#1255](https://github.com/Zaneris/passenger/issues/1255)).
- **TextMate colouring is faster** for most languages, CSS and SCSS in under half their time, with Tint 0.2.3 ([#1124](https://github.com/Zaneris/passenger/pull/1124), thanks to Sébastien Ros).
