Passenger 0.3.0 is an IDE for Godot 4 games in C# and GDScript: it runs, debugs and Hot Reloads a game, profiles its C# and GDScript in one call tree, checks its C# against its scenes, reads its GDScript and shaders as Godot does, shows the running game's tree and values beside your code, and lets your coding agent play it. Blazor's WebAssembly components now debug in the browser, Avalonia and WPF apps take XAML Hot Reload, Aspire's window charts each resource's metrics, and Publish ships container images. Tools like these are usually found in paid IDEs or add-ons; in Passenger they are part of the IDE. It is still free and open source under MIT, and everything this release closed is in its [0.3.0 milestone](https://github.com/Zaneris/passenger/milestone/6).

## Godot 4: run, debug and Hot Reload

- **Run, debug, profile and Hot Reload a Godot game**, in C# or in GDScript alone ([#1065](https://github.com/Zaneris/passenger/issues/1065), [#1086](https://github.com/Zaneris/passenger/issues/1086), [#1105](https://github.com/Zaneris/passenger/issues/1105), [#1125](https://github.com/Zaneris/passenger/issues/1125)), with the Godot found and its version in Settings › Godot ([#1087](https://github.com/Zaneris/passenger/issues/1087)).
- **Debug C# and GDScript at once** ([#1069](https://github.com/Zaneris/passenger/issues/1069)): a breakpoint in either language stops the game, and a script you save reloads in it ([#1188](https://github.com/Zaneris/passenger/issues/1188), [#1179](https://github.com/Zaneris/passenger/issues/1179)).
- **Run Current Scene** plays the scene open in the editor ([#1272](https://github.com/Zaneris/passenger/issues/1272)), and **Run Another Copy** plays up to 16 copies for multiplayer, debugged as one group that one Stop ends ([#1117](https://github.com/Zaneris/passenger/issues/1117)).
- **The game in a pane beside its code**, on Windows, macOS and Linux under X11 ([#1127](https://github.com/Zaneris/passenger/issues/1127)): it takes the keys when you click it, and Ctrl+F11 takes them back.
- **Godot's types read as you think of them** in Variables and the hover, Vector3, Transform2D and Color among them ([#1110](https://github.com/Zaneris/passenger/issues/1110)), and **Mute Game Audio** silences a debugged game ([#1119](https://github.com/Zaneris/passenger/issues/1119)).
- **New Solution and New Project make a Godot 4 game**, C# or GDScript, ready to run ([#1113](https://github.com/Zaneris/passenger/issues/1113), [#1140](https://github.com/Zaneris/passenger/issues/1140)), and **Publish exports it** through its export presets ([#1112](https://github.com/Zaneris/passenger/issues/1112)).
- **project.godot opens as a page** of its main scene, autoloads, input map, export presets and plugins ([#1132](https://github.com/Zaneris/passenger/issues/1132)), and a project's launch profiles run as Passenger's own configurations do, Chickensoft's `%GODOT%` ones too ([#1176](https://github.com/Zaneris/passenger/issues/1176)).
- **F1 opens Godot's documentation** at the class or member ([#1118](https://github.com/Zaneris/passenger/issues/1118)), C# script templates fit Godot's Attach Script dialog ([#1194](https://github.com/Zaneris/passenger/issues/1194)), and Ogg and MP3 files play from their preview ([#1155](https://github.com/Zaneris/passenger/issues/1155)).
- **Games stop and print as they should**: a stopped game shows as stopped beside another running ([#1106](https://github.com/Zaneris/passenger/issues/1106), [#1206](https://github.com/Zaneris/passenger/issues/1206)), Windows' external console shows what a game prints ([#1138](https://github.com/Zaneris/passenger/issues/1138)), and an error raised every frame stays one counted entry ([#1135](https://github.com/Zaneris/passenger/issues/1135), [#1241](https://github.com/Zaneris/passenger/issues/1241)).

## Godot 4: your scenes, read with your code

- **C# checked against its scenes** ([#1067](https://github.com/Zaneris/passenger/issues/1067)): `GetNode<T>` paths and types, `res://` paths and `[Export]` values complete and are checked, and a rename reaches the scenes.
- **Signals and their handlers lead to each other** ([#1068](https://github.com/Zaneris/passenger/issues/1068), [#1100](https://github.com/Zaneris/passenger/issues/1100)), and a connection to a missing method, an `EmitSignal` or a `uid://` path that names nothing is marked ([#1101](https://github.com/Zaneris/passenger/issues/1101)).
- **Every string Godot takes completes, is checked and renames**: input actions, groups, animations, autoloads, shader parameters, translations, layers and theme items ([#1108](https://github.com/Zaneris/passenger/issues/1108), [#1136](https://github.com/Zaneris/passenger/issues/1136), [#1215](https://github.com/Zaneris/passenger/issues/1215)).
- **An open scene is marked where Godot would not load it**, with fixes ([#1104](https://github.com/Zaneris/passenger/issues/1104), [#1131](https://github.com/Zaneris/passenger/issues/1131)), in a game of GDScript alone and on Windows too ([#1165](https://github.com/Zaneris/passenger/issues/1165), [#1214](https://github.com/Zaneris/passenger/issues/1214), [#1220](https://github.com/Zaneris/passenger/issues/1220)).
- **Scenes beside the code**: a script shows the scenes it runs in ([#1130](https://github.com/Zaneris/passenger/issues/1130)), and a scene's tree is its outline in Structure, where its nodes' properties are edited ([#1114](https://github.com/Zaneris/passenger/issues/1114), [#1202](https://github.com/Zaneris/passenger/issues/1202), [#1240](https://github.com/Zaneris/passenger/issues/1240)).
- **C# and GDScript lead to each other**: calls, connections, usages and renames across both ([#1115](https://github.com/Zaneris/passenger/issues/1115), [#1166](https://github.com/Zaneris/passenger/issues/1166), [#1169](https://github.com/Zaneris/passenger/issues/1169), [#1237](https://github.com/Zaneris/passenger/issues/1237), [#1273](https://github.com/Zaneris/passenger/issues/1273)).
- **What your Godot editor holds unsaved is safe**: Passenger asks before it writes over it ([#1190](https://github.com/Zaneris/passenger/issues/1190), [#1224](https://github.com/Zaneris/passenger/issues/1224), [#1270](https://github.com/Zaneris/passenger/issues/1270)).
- **Large projects stay fast**: a key in a scene or script costs what it changed, not the project's size ([#1199](https://github.com/Zaneris/passenger/issues/1199)).

## Godot 4: GDScript and shaders

- **GDScript read as Godot reads it** ([#1196](https://github.com/Zaneris/passenger/issues/1196), [#1228](https://github.com/Zaneris/passenger/issues/1228), [#1245](https://github.com/Zaneris/passenger/issues/1245)): Passenger's port of Godot's parser and analyzer gives Godot's warnings and errors with their fixes, and answers completion, the hover, Find Usages, Rename and the outline, mostly without starting Godot.
- **GDScript marks only what Godot would**: no false `extends Node` where no Godot is installed, no wrong argument count past a rest parameter, and marks in Godot's order ([#1266](https://github.com/Zaneris/passenger/issues/1266), [#1211](https://github.com/Zaneris/passenger/issues/1211), [#1277](https://github.com/Zaneris/passenger/issues/1277)).
- **Reformat Code follows Godot's style guide**, and Order Script's Parts puts a script in its order ([#1197](https://github.com/Zaneris/passenger/issues/1197), [#1230](https://github.com/Zaneris/passenger/issues/1230)).
- **Refactorings that reach every caller**: Rename, Change Signature and Move, through scenes' connections and C# strings ([#1198](https://github.com/Zaneris/passenger/issues/1198)).
- **Shaders checked as Godot's compiler checks them**, every error and warning at once with no Godot running, and their built-ins completed and explained on hover ([#1182](https://github.com/Zaneris/passenger/issues/1182), [#1256](https://github.com/Zaneris/passenger/issues/1256), [#1205](https://github.com/Zaneris/passenger/issues/1205)).
- **Your project stays as you left it**: the headless Godot behind GDScript's language server never changes it, nor undoes what your own Godot writes ([#1180](https://github.com/Zaneris/passenger/issues/1180), [#1187](https://github.com/Zaneris/passenger/issues/1187), [#1269](https://github.com/Zaneris/passenger/issues/1269)).

## Godot 4: the running game

- **The running game's scene tree, values, errors and monitors** in the Live Visual Tree, following each game as it changes ([#1066](https://github.com/Zaneris/passenger/issues/1066), [#1090](https://github.com/Zaneris/passenger/issues/1090)).
- **Tune values while it plays**, with a swatch, a slider or a vector's parts, and Keep writes one back into its scene ([#1126](https://github.com/Zaneris/passenger/issues/1126), [#1102](https://github.com/Zaneris/passenger/issues/1102)).
- **Click in the game to select a node**, and pause the game or step it a frame ([#1111](https://github.com/Zaneris/passenger/issues/1111), [#1231](https://github.com/Zaneris/passenger/issues/1231)).
- **Members' values show in your code as the game plays** ([#1129](https://github.com/Zaneris/passenger/issues/1129)), the game's errors stay pinned to their lines after the run ([#1128](https://github.com/Zaneris/passenger/issues/1128)), and frame time and your own monitors are charted live ([#1116](https://github.com/Zaneris/passenger/issues/1116)).
- **One profile, both languages**: GDScript's functions and Godot's frame times beside the C# in one call tree, a slow frame opening on what it spent, and memory snapshots of the game ([#1096](https://github.com/Zaneris/passenger/issues/1096), [#1201](https://github.com/Zaneris/passenger/issues/1201)).
- **GdUnit4, GUT and GoDotTest tests** are found, run and debugged in the Unit Tests window ([#1109](https://github.com/Zaneris/passenger/issues/1109), [#1146](https://github.com/Zaneris/passenger/issues/1146), [#1177](https://github.com/Zaneris/passenger/issues/1177), [#1209](https://github.com/Zaneris/passenger/issues/1209)).

## Your coding agent

- **Agents play and debug a Godot game** as they do an Avalonia app: its tree, its values, clicks and keys, a breakpoint's stop, and every copy running ([#1070](https://github.com/Zaneris/passenger/issues/1070), [#1159](https://github.com/Zaneris/passenger/issues/1159), [#1181](https://github.com/Zaneris/passenger/issues/1181), [#1160](https://github.com/Zaneris/passenger/issues/1160), [#1162](https://github.com/Zaneris/passenger/issues/1162), [#1178](https://github.com/Zaneris/passenger/issues/1178), [#1223](https://github.com/Zaneris/passenger/issues/1223)).

- **Agents change scenes in your Godot editor** with one new tool, `godot_editor`, each change one step of Godot's Undo ([#1191](https://github.com/Zaneris/passenger/issues/1191), [#1229](https://github.com/Zaneris/passenger/issues/1229), [#1232](https://github.com/Zaneris/passenger/issues/1232)).
- **More of the IDE reaches agents**: GDScript's fixes and warning codes ([#1239](https://github.com/Zaneris/passenger/issues/1239), [#1213](https://github.com/Zaneris/passenger/issues/1213)), Aspire's metrics ([#1235](https://github.com/Zaneris/passenger/issues/1235)) and a project's framework choice ([#1097](https://github.com/Zaneris/passenger/issues/1097)); diagnostics of an unchanged file answer in about 0.1 s ([#1238](https://github.com/Zaneris/passenger/issues/1238)), and output reads the debugged program's when no console is named ([#1088](https://github.com/Zaneris/passenger/issues/1088)).

## Faster and leaner

## Worth knowing

- GDScript works with any Godot 4; C# needs Godot's .NET build. The Game window takes Godot 4.4 or newer (4.5 or newer on macOS), and under Wayland it needs XWayland.
- On Godot 4.8's betas, GdUnit4's tests that need the engine don't run yet, since GdUnit4's runner doesn't build there; each such test's details say why. They run on Godot 4.7.
- Passenger's command on Linux is now `passenger-ide` ([#1083](https://github.com/Zaneris/passenger/issues/1083)), so it never meets Phusion Passenger's `passenger`; an install's old link moves to it, and `install.sh` names a font package your distribution lacks.
- A `.gdshaderinc` is checked on its own, as Godot's shader editor checks one.
- Debugging Blazor's WebAssembly takes Chrome, Edge, Chromium or Brave, which Passenger starts on a profile of its own.
- Each release is now tried on a standing set of real Godot projects, C# and GDScript, and 0.3.0 fixes every finding ([#1170](https://github.com/Zaneris/passenger/issues/1170), [#1195](https://github.com/Zaneris/passenger/issues/1195)).
