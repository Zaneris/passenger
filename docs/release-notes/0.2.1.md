Passenger 0.2.1 is a release of fixes and speed: long lists, searches and the terminal do far less work, a run starts without building when nothing changed, and a busy machine no longer makes a search miss matches or a project's routes go missing. It is still free and open source under MIT, it moves to .NET 11 RC3 (a security release), and everything it closed is in its [0.2.1 milestone](https://github.com/Zaneris/passenger/milestone/4).

## Faster

- **Every list reuses its rows**, the Explorer, Problems, Variables, the Git log, completion, the search popups, the profiler's and memory's views and the rest: scrolling a list of thousands costs what scrolling a short one does, and a row's icons are drawn for a fraction of what they cost ([#530](https://github.com/Zaneris/passenger/issues/530)).
- **A run starts without building** when nothing its build reads has changed, and several services of a run are built in one go ([#466](https://github.com/Zaneris/passenger/issues/466), [#467](https://github.com/Zaneris/passenger/issues/467)).
- **Find in Files skips files that can't match** before reading them ([#533](https://github.com/Zaneris/passenger/issues/533)), **Go to File** rules most files out at once ([#535](https://github.com/Zaneris/passenger/issues/535)), and **the terminal** writes plain text in runs rather than a character at a time ([#534](https://github.com/Zaneris/passenger/issues/534)).
- **With solution-wide analysis on,** the open file's squiggles no longer wait for the whole project's analysis, and a burst of keys no longer has the solution analysed again for each one.
- The Migrations window runs fewer `dotnet ef` processes for each command ([#465](https://github.com/Zaneris/passenger/issues/465)).

## Fixed

- **A regex search on a busy machine** no longer misses matches, a search that stops says so, and Replace never changes only part of a file's matches ([#539](https://github.com/Zaneris/passenger/issues/539)).
- **The diff view's scroll bar** takes its clicks under the change markers ([#538](https://github.com/Zaneris/passenger/issues/538)), and **the Solution Explorer's scroll bar** drags without losing hold ([#528](https://github.com/Zaneris/passenger/issues/528)). Thanks to Jimmacle for both reports.
- **A folder opened on macOS through another letter case** (`cd ~/documents/dev/app`) is opened as the disk spells it, so its builds no longer delete what an earlier build wrote ([#537](https://github.com/Zaneris/passenger/issues/537)).
- **Run pressed while a build works** waits for it instead of being refused; a change to global.json's SDK versions builds again; three test rows of one name are told apart; Refresh keeps the right project's Dependencies open; and a mark no longer grows over text typed at its start ([#540](https://github.com/Zaneris/passenger/issues/540)).
- **A web project that finishes loading while its routes are read** shows its routes in Endpoints, beside its code and against its requests, where they stayed missing until one of its files was edited.
- **Run, Debug or Profile of a compose app** no longer fails now and then with "ports are not available" on a busy machine: a port Passenger chooses for a service is free at every address and outside the range the system lends its connections, and one taken anyway before the engine publishes it is chosen again.
- **A folder deleted while its project builds** no longer leaves another open window's projects unloaded behind "There were problems loading project": the helper process every window shares for MSBuild is started again, and what it hadn't finished is asked of the new one.
- A container service that the debugger can't reach is never held at its start ([#517](https://github.com/Zaneris/passenger/issues/517), [#519](https://github.com/Zaneris/passenger/issues/519)), and on Linux a debugged program's exit code is no longer lost ([#478](https://github.com/Zaneris/passenger/issues/478)).

## Also new

- **Save as Launch Profile** shares a run configuration made in Passenger through its project's `launchSettings.json`, which `dotnet run` and every other IDE read ([#527](https://github.com/Zaneris/passenger/issues/527)). The idea is MangoDevx's.
